# FuFumidi v3.1.13

## 修复
- **更新不再因中断损坏工具**：更新流程重构为「主进程预下载完整离线安装包（多镜像回退 + 大小校验）→ 校验通过后本地静默安装」。下载过程中关闭/中断只残留临时文件，当前安装完全不受影响
- **下载进度可见**：更新包下载进度在应用内显示（每 5% + 完成提示）；下载失败明确提示「当前安装未受影响，可稍后重试」
- **安装完成保护**：守护进程在安装器退出后校验核心文件完整性，完整才重启主程序（承接 3.1.12）

## 更新方式
- 3.1.x 用户：应用内自动更新（或下载 `FuFumidi.Install.exe` 离线包覆盖安装）
- 新用户：下载 `FuFumidi-Setup-3.1.13.exe` 完整安装
