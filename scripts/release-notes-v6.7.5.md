# FuFumidi 6.7.5（修卡音与音色卡住）

> 本版只动播放链路，6.7.3 / 6.7.4 的视频背景与性能改动全部保留。已装旧版的用户走正常更新。

## 修复 · 播放时某个音一直响不停

这是延音踏板（CC64）的收尾问题，两条独立路径：

**① 文件里踏板按下却没抬起。** 大量 MIDI（尤其是转换/导出得到的）只有 `CC64=127`，没有配对的 `CC64=0`。
原实现遇到这种「没抬起的踏板」会把该通道上所有音符的结束时刻延长到曲尾 —— 等于踏板一响，
整首都在响。现在这类区间按文件缺陷处理：音符保留自己的时值，只在曲尾补一条踏板抬起收尾。

**② 暂停 / 跳转后的残留延音。** `All Notes Off`（CC123）只是让音符进入释放阶段，
踏板按下时释放会被无限延长（FluidSynth 的 sustain 是通道级状态，不会因为 All Sound Off 自动清除）。
现在 panic 会先把 CC64/CC65/CC66 复位为 0，再发 CC120 / CC123。

另外加了一层兜底：音序器里的 note-off 万一随队列一起被清掉（换音色库、时钟停走），
这条音会一直响到下一次停止。现在播放时每 25ms 检查活跃音符表，对「超时 2.5 秒且同通道同音高
没有更晚的音」的条目补发一次直连 note-off。控制台 Verbose 级别会提示补了几条。

## 修复 · 卡在一个音色上播放很久

**① 切音色库后没有重发音色。** MIDI 规范里 Bank Select（CC0）只改库号，必须紧跟一次
Program Change 才真正换预设。原实现只比较音色号数值，切库但音色号没变时这次切换被吞掉，
该通道会一直用旧库的音色。现在切库后强制重发一次音色（实时播放与离线导出同步修）。

**② 通道类型是单向的。** 一个通道被设成鼓组后不会自己变回旋律，而合成器实例是跨曲目复用的，
上一首在这个通道打过鼓，下一首同通道的旋律音符仍用鼓声。现在按音符语义双向同步。

**③ 音符试听污染 ch0。** 编辑器里点音符试听直接改 ch0 的音色，绕过了下发缓存；
之后播放时若音色号与缓存相同就不再重发，整首沿用试听音色。现在试听结束会作废该通道缓存。

**④ 音色库里缺这个音色号。** FluidSynth 选不到预设时会沿用上一个音色，整条通道一直错下去。
现在缺失/越界的音色号退回 0 号钢琴；清单没解析出来时保持原行为，不做猜测。

## 修复 · MusicXML 第 10 个声部变成鼓

导入时按 `part 序号 % 15` 分配通道，第 10 个声部（序号 9）正好落到 MIDI 保留的鼓通道 ch9，
整轨用鼓组音色发声。导出总谱时同一个位置也会被标成鼓通道。两处都改为跳过 ch9。

## 修复 · 外接 MIDI 硬件输出暂停后不消音

暂停时只发了 ch0 的 All Notes Off，多通道文件（钢琴 ch0 / 弦乐 ch1…）其余通道在外接音源上
会一直响。现在遍历全部 16 个通道，并同时复位踏板。

## 升级后请验

1. 播一首带踏板的钢琴曲，暂停再继续：不应有音残留；
2. 播多轨曲目，切一段音色库不同的段落：音色应按谱面切换，不应整段用同一个音色；
3. 如果你接了 MIDI 硬件音源，暂停后所有通道都应静音。
