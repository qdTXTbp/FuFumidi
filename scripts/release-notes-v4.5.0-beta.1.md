# FuFumidi v4.5.0-beta.1

内测版。本版聚焦 **UTAU 与 DiffSinger 模块融合**、**AI 声库下载体验**与 **OpenUTAU 式可视化编辑**。

> 这是测试版（prerelease），仅「设置 → 更新 → 测试版通道」开启的用户可收到。
> 参与内测前，请先从正式版升级到带双通道的版本。

## 新功能

### UTAU 与 DiffSinger 模块融合

- 制作音频时可在 **UTAU 声库与 DiffSinger AI 声库之间自由切换**：
  UTAU 工作台的「曲谱与调声 / 合成渲染」顶栏新增引擎切换器（UTAU ↔ DiffSinger），
  选好声库点渲染即自动走对应引擎（UTAU 走拼接合成，DiffSinger 走 AI 推理），无需换页。
- 「声库制作」页的声库列表改为双分组展示：**UTAU 声库** + **DiffSinger AI 声库**，
  同一处即可查看与切换。
- 制作声库仍**只允许常规 UTAU 声库**（导出声库为 oto.ini 音源库），不支持制作 DiffSinger AI 声库——
  AI 声库统一从「资源中心 → 模型管理 → DiffSinger 声库」下载。

### OpenUTAU 式音素视图

- 曲谱（钢琴卷帘）新增「**音素视图**」开关：在音符内绘制「辅音 → 元音」的音素切分，
  直观看到发音结构，接近 OpenUTAU 的观感（分界比例按子音速度估算）。
- 已有的音高曲线手绘 / 控制点编辑、参数车道、框选 / 多选 / 撤销重做等能力保持不变。

### AI 声库下载走常规下载链路

- DiffSinger AI 声库下载现已与常规模型下载**共用同一套体验**：
  顶部全局通知条（弹窗 + 实时速度 + 进度 + 取消）、卡片内进度显示阶段文案与速度，
  解压 / 安装阶段有匀速爬条与流光动画。
- 全局通知条会显示声库的**可读名称**（如「神里绫华（原神）」），不再显示内部 id。

## 修复

- **「资源中心」显示可下载声库数量为 0**。DiffSinger 声库不在常规模型清单里，
  导致「模型管理」页的 DiffSinger 页签徽标与页面副标题恒显示 0，与实际可下载的 163 个声库不符。
  现已接入共享统计，页签显示真实可下载数量（未加载完成前显示「…」而非误报 0）。

## 构建

- 修复打包配置：`files` 规则此前只排除默认输出目录 `release/`，
  自定义输出目录（如本地测试用的 `release-test/`）会被当作源码打进 `app.asar`，
  导致包体从 ~64MB 膨胀到 2GB+。现已补充排除规则。

## 升级说明

- 应用内更新：设置 → 更新 → 打开「测试版通道」→ 检查更新
- 全新安装：运行 `FuFumidi Setup 4.5.0-beta.1.exe`
- 本版不涉及安装 / 卸载与数据目录结构，升级不会动你的曲库、模型、声库与设置。
