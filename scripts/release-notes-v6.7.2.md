# FuFumidi 6.7.2（修「卷帘」没声音）

> 只动「卷帘」页签。已装 6.7.1 的用户走正常更新（增量包约 164 MB）。

## 修复 · 点开始只滚动、没有声音

「卷帘」原先是照 CodePen 那套**独立时钟**做的：它自己算时间、自己滚画面，从不碰音频引擎 ——
所以永远不会有声音。

现在这套走带接到播放器上：

| 按钮 | 现在的行为 |
|---|---|
| 开始 | 回到开头并**真正播放**（`seekSec(0)` + `togglePlay`） |
| 暂停 / 继续 | 真正的播放/暂停，不是只停画面 |
| 重置 | 停止播放并归零 |
| 重新播放 | 从头再播 |

播放头时间也改成**播放中直接问播放器**（逐帧），而不是读 30fps 节流的 store 值，
滚动与声音因此严格同步，顺带继承了播放器的「跳空白」与引擎自愈。

## 修复 · 画面不逐帧刷新

改写走带时把逐帧循环的启动漏掉了，导致播放头不动、自动跟随与高亮也不更新。已补上。

## 调整 · BPM 现在改的是真实速度

「BPM（可选）」以前只改预览倍率（因为没声音），现在直接改播放速度；
离开本页、切换曲目或点重置会恢复原速。

## 升级后请验

1. 进「音乐 → 卷帘」，选一首曲目，点**开始**：应当**听到声音**，播放头随之前进；
2. 点暂停：声音与画面同时停；再点继续从原处接上；
3. 点重置：回到开头并停止。
