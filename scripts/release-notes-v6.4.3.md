# FuFumidi 6.4.3

## 资源中心 · 运行时包

- 修：MIROS / hFT-Transformer / YourMT3+ / hnsep 这些「下载一个压缩包再解开」的运行时包**装不上** ——
  解包时把压缩包路径当成 AdmZip 对象用，报 `zip.getEntries is not a function`，5 GB 的包下完卡在解包。
- 改为按路径安全解压：超过 1 GiB 的包走**流式解压**（只读中央目录、逐条目 inflate 落盘），
  主进程不再把整包读进内存，解压期间界面不再卡死（实测 4.5 GB 包：31 s、峰值内存 71 MB）。
- 大包解压失败不必重下：压缩包通过体积 / SHA256 校验后，**解压失败会保留**，重试直接复用；
  只有校验失败才丢弃。解压阶段显示已解出字节的百分比。
- 安全规则（路径穿越 / 重名条目 / 解压炸弹）收敛成唯一实现，实例与路径两种入口共用；
  新增 11 项回归测试（含「传路径不再抛 TypeError」）。

## 转录 · MuScriptor

- 修：「同一段旋律隔几秒换一次音色 + 音符丢失」。跨块延音（`prelude_forcing`）**恢复默认开** ——
  它让模型在 5 秒块边界把没结束的音**按原乐器**续进下一块。关掉它的代价有实测：
  相邻分块换乐器组 1→16 次、音符少 22%、非鼓轨 5→9 条。
- 僵尸长音仍由音频证据收尾兜底（该钩子本就是为 prelude 开设计的）；界面上的「长音修复」保留。
- 该开关改名「跨块延音（模型续接）」：它控制的是模型侧续接，不只是解码后的缝合。
- 只有显式关闭跨块延音时，才回到「模型自己猜 tie + 解码后缝合补连续性」的老路。
