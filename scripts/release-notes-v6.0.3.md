# FuFumidi 6.0.3

> 6.0.2 之后的收尾版：分轨 ZIP 打包、编排页分标签撤销、i18n 欠账清零、翻唱咬字手动修正入口。

## 分轨导出（P0-4c）

- 勾选「分轨导出」后新增「打包为一个 ZIP（推荐）」（默认开）：桌面版只弹一次保存对话框，所有分轨进一个 ZIP。

## 编排页分标签撤销（P1-13）

- 「视图 → 编排」撤销/重做按曲目标签隔离：切走是独立历史，切回撤销记录仍在；横向滚动位置随标签恢复。

## 多语言（P0-8）

- **英文 / 日文历史欠账清零**：累计补齐约 1080 条英文 + 1020 条日文翻译；
  从此新代码缺失 EN/JA 会被 `npm run audit` 直接拦截。

## 翻唱（P1-5）

- 咬字校验卡新增「去改歌词」入口：改这些句的歌词后重新合成，未改动的句子复用缓存、只重跑改过的句。

## 其他

- 完成度审计文档入库（28 个工作包逐项状态与证据）。
