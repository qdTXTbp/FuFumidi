# FuFumidi 6.6.1

本版修的是 6.6.0 收到的一条用户反馈：「限定乐器用不懂了」以及
「自动识别时人声断断续续，背景音乐都正常」。查下来不是用户不会用，
而是三个真 bug 叠了一个模型侧的召回漏洞。

## 人声断断续续、伴奏正常

默认的「自动锁定（音色稳定）」档会先扫描整曲的 3 段代表音频，
把模型听到的乐器锁成**整曲白名单**（官方 `transcribe(instruments=...)` 硬约束）：
没进白名单的乐器，整首都不会出现。人声的音符数通常远少于伴奏，
而选窗又偏向能量最高的片段（副歌、伴奏最响处），很容易被
「音符数门槛 / 3% 占比 / 最多 8 组」当成长尾剪掉 —— 于是人声旋律整段消失，
背景乐器因为都被锁定了反而一切正常。

本版：

- 人声（voice）与鼓（drums）一起列为「只要模型在任何一段听到就必留」，
  名额被 `max_groups` 截断时也不会被挤掉；
- 引擎再加一层双保险：预分析只要听到过人声或鼓，就一定补回允许组；
- 预分析日志新增「未锁定（探测音符太少或名额已满）：…」一行，
  直接写清楚哪些乐器被排除、该切哪个模式；
- 自动锁定档的界面说明里点名这个风险，并给出临时解法：
  **切「不限定（官方自动识别）」，或在「手动限定」里勾上「人声」**。

## 手动限定「不会用了」

- **改成中文点选**：17 个常用乐器组（人声 / 鼓组 / 钢琴 / 电钢琴 / 木吉他 /
  清音电吉他 / 电贝斯 / 弦乐组 / 合成主音 …）点一下就加入，
  可展开官方全部 35 组；输入框保留给需要手写 ID 的高级用法。
- **看得见自己选了什么**：下方显示已选中文名；一个都没选时明确提示
  「现在等同『不限定（官方自动识别）』」，并提醒带人声的歌务必勾「人声」。
- **「清空」不再跳档**：旧按钮会把值设成 `none` 并让整个手动输入区消失，
  想清空重填反而变成「只能用自动识别了」。现在拆成
  「清空所选」（留在手动档）和「切回自动识别」两个按钮。
- **新增「人声 + 伴奏（带唱的歌）」预设**，一键填好常见带唱编制。

## 一个隐蔽的参数 bug

界面写的是「限定乐器组（留空 = 官方自动识别）」，但手动档留空时前端
根本不发 `muscriptor_instruments` 这个键，引擎会把缺省值解释成默认
`probe`（自动锁定）—— 也就是说点了「手动限定」却什么都没填，
跑出来的仍是那个会挡掉人声的自动锁定档。现在始终显式传值，
三档行为与文案完全一致。
