# FuFumidi 6.7.3（修复视频导出背景）

> 本版只修复「转换 → 视频导出」的背景设置，卷帘、音频与其它功能与 6.7.2 相同。

## 修复 · 导出视频没有壁纸

视频导出与预览共用同一套绘制函数，但传给绘制函数的背景参数只包含 `mode` 和 `video`；`image`、`color`、`blur`、`dim` 没有传进去。结果：

- 图片壁纸收不到图片，退回主题渐变；
- 纯色、模糊、暗化设置丢失；
- 动态壁纸的模糊/暗化不一致。

现在 `drawOpts()` 完整透传背景对象，并附带已解码的图片元素；视频预览与导出的背景都和「可视化」页使用同一份设置。

## 升级后请验

1. 转换 → 视频导出，背景选「图片」或「动态壁纸」；
2. 预览和导出的 MP4 背景应一致；
3. 切换模糊/暗化后重新导出，成片应反映新参数。

## 说明

- 这是完整安装包更新，不是热补丁：修复位于 `app.asar` 内的 renderer 代码，超出 HOTPATCH.md 允许范围。
- 背景选择仍以「可视化」页/导出页的 `fufumidi.viz.bg` 设置为准；应用整窗壁纸与瀑布流壁纸是两套独立设置。
