# FuFumidi 6.0.1

> 6.0.0 发布后的功能补齐版：DAW 互通、可选 AI 生成、翻唱咬字校验 UI 一起进入安装包。
> （6.0.0 的安装包构建早于这三项，6.0.1 起安装包与源码一致。）

## DAW 互通（P2-5）

- 转换页新增「导出 DAWproject」：把曲目按 DAWproject 1.0 导出（ZIP：project.xml + metadata.xml），
  包含 MIDI 音符轨、速度、拍号、标记；Studio One / Bitwig / Cubase 等支持该格式的 DAW 可尝试导入。
- 只覆盖音符轨子集：音频事件、Warp、插件状态、自动化曲线暂不导出；**尚未在 DAW 实机导入验证**。

## AI 生成（P2-6，可选、默认关）

- 设置 → 功能（专家模式）新增「AI 生成（可选）」：默认关闭，打开后使用你自备的**本地生成命令**
  （不内置模型、不联网），命令契约 `--job <job.json> --outdir <dir>`。
- 所有产物强制带 **AI 生成标注**（provider/model/时间/提示词指纹）；命令失败、无结果文件、结果越界都会明确报错。

## 翻唱（P1-5）

- 合成结果卡新增「咬字校验」：逐句显示字保留率 <95% 的句子（可能丢字/糊字）与处理建议；
  字级明细在 `gsv/gsv_lines.json` 的 `charAlign`。

## 修复

- CNB 发布：`make_latest` 是字符串枚举，修复后新版本才会成为 `releases/latest`（6.0.0 首次上传时踩到）。
