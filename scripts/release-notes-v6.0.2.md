# FuFumidi 6.0.2

> 6.0.1 之后的两项体验补齐：分轨导出一次打包 ZIP、编排页按曲目标签隔离撤销栈。

## 分轨导出打包（P0-4c）

- 转换页勾选「分轨导出」后，新增「打包为一个 ZIP（推荐）」（默认开）：桌面版只弹一次保存对话框，
  所有分轨写进一个 ZIP，文件名 = 曲名 + 轨名 + `_stem.wav`。
- 网页端或主进程不支持时自动回退为逐文件保存；文件清单与命名保持可追溯。

## 编排页分标签撤销（P1-13）

- 「视图 → 编排」的撤销/重做按**曲目标签**隔离：切到别的曲目是独立历史，切回来撤销记录仍在；
  横向滚动位置也随标签保存/恢复。
- 说明：钢琴卷帘编辑器内部撤销仍随编辑器实例（切走再回来是重新进入编辑器）。

## 升级

- 数据/设置/曲库格式不变；覆盖安装即可。
