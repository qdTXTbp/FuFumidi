# FuFumidi v3.3.0

本次更新聚焦「播放体验与音乐库」，并带来多项稳定性修复。建议所有用户更新。

## ✨ 新增

- **专业音效调节**：10 段均衡器 + 流行/摇滚/古典等 7 种预设 + 低音增强与空间声效果，MIDI 与音频曲目共用同一条效果链
- **播放模式与无缝播放**：顺序 / 随机 / 单曲循环 / 列表循环；播放期间预解析下一首，曲尾淡出 + 曲首淡入平滑衔接
- **断点续播 / 书签 / 睡眠定时**：记录并跳转播放进度；15/30/60/90 分钟定时，到点自动淡出停止（音频曲目同样生效）
- **智能音乐库**：按艺术家 / 专辑 / 流派 / 文件夹整理；最近 / 最常播放智能列表；曲目标签编辑（艺术家 / 专辑 / 流派 / 封面）
- **音频曲目播放**：mp3 / wav / flac 等直接入库播放，与 MIDI 同用音效链
- **歌词**：.lrc 同名自动加载，支持导入导出
- **托盘与自启**：最小化 / 关闭到系统托盘后台播放（防节流断音）、开机自启开关
- **清除用户数据**：设置页卸载旁新增按钮，一键清除下载的模型 / 音色与播放数据（不动曲库歌单）
- **Salamander Grand Piano** 音色上架音色工坊（国内镜像可达）

## 🛠 修复

- **并行转录真正生效**：主进程多引擎进程池按负载调度（1-4 路，GPU 环境自动降 1 路），空闲自动回收
- **转译 ↔ 视图·乐谱切换卡顿**：Verovio 刻版按条件指纹复用，切页零重刻，需要重刻时避开切换动画
- **大模型下载超时失败**：连接 / 读取超时分离 + 停滞看门狗 + 断点续传，长下载不再前功尽弃
- **升级后转录模型无法下载（ENOENT）**：安装器替换内置模型目录后残留断链 junction，现启动时与每次下载前自动清理；模型 / 音色迁移到用户数据目录，升级不再丢失
- **分卷模型下载报 EPERM**：写入流在错误 / 暂停路径未销毁导致句柄泄漏与 delete-pending 竞态，现已正确释放；下载失败 / 暂停保留已下载分卷，断点续传成立
- **播放栏图标重复**：播放模式换专用图标，节拍器重画为真实造型
- **UTAU 增强**：参数预设存用、声库 zip 拖拽导入、试听与 oto 自动建议、整轨人声渲染

## 📦 安装与更新

- 完整安装包：`FuFumidi-Setup-3.3.0.exe`
- 离线更新包：`FuFumidi.Install.exe`（应用内「检查更新」自动使用，固定名覆盖）
- 3.0.0 及以上版本可直接在应用内「检查更新」增量升级
