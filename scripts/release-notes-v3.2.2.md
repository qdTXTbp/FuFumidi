# FuFumidi v3.2.2

## 新增 / 优化
- **功能页整合**：顶部导航合并为「首页 / 音乐 / 视图 / 转译 / 资源中心 / UTAU」，减少杂乱入口，直达核心功能
- **首页工作区整合**：快速开始卡片收敛为「音乐 / 视图 / 转译 / 资源中心」，入口更聚焦；移除重复的首页卡片
- **资源中心整合**：模型管理 / 音色工坊 / 资源管理统一收进资源中心，支持页签切换；`/models`、`/soundfonts` 旧入口自动跳转到对应页签
- **内部跳转深链**：播放 / 歌词 / 编辑、可视化 / 分析 / 乐谱、转录 / 转换等旧跳转自动落到对应分组页签，导航不再丢失上下文
- **动画动效优化**：
  - 功能页切换更顺滑（缓动曲线、淡入淡出 + 轻微位移/缩放，更贴近系统动效）
  - 音乐 / 视图 / 转译内部子页签、资源中心页签切换增加平滑过渡
  - 尊重系统「减少动态效果」设置
- **曲目卡片描边**：最近曲目与歌单中的曲目选项卡增加边框，悬停/选中态有明确描边反馈

## 修复
- 修复视图整合后部分旧入口跳转失效的问题（歌单、乐谱、编辑、转录等内部互跳）
- 修复模型管理 / 音色工坊在资源中心合并后入口缺失的问题
- 修复歌单曲目名称显示与工具区布局，提升可读性

## 更新方式
- 3.2.1 / 3.2.0 / 3.1.x 用户：应用内自动更新（增量更新器差分下载），或下载 `FuFumidi.Install.exe` 离线包覆盖安装
- 新用户：下载 `FuFumidi-Setup-3.2.2.exe` 完整安装
