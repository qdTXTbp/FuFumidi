# FuFumidi v3.1.12

## 修复
- **升级不再因镜像不稳定损坏工具**：更新器由单一镜像改为多镜像源（ghfast / gh-proxy / ghproxy.net / GitHub 官方），启动更新前自动探测可用源；更新失败不再盲目重启残缺程序
- **核心文件完整性自检**：更新后守护进程重启前校验 app.asar，损坏时不启动；应用启动时检测核心文件缺失/损坏，设置面板明确提示重新更新或重装
- **GPU 安装防重复触发**：安装通知条存在时按钮禁用、无法重复发起安装/导入/卸载，安装进行中通知条不可关闭

## 更新方式
- 3.1.x 用户：应用内自动更新（或下载 `FuFumidi.Install.exe` 离线包覆盖安装）
- 新用户：下载 `FuFumidi-Setup-3.1.12.exe` 完整安装
