# FuFumidi v3.2.0

## 新功能
- **音频处理改为 MSST 分离引擎**：人声 / 乐器 / 伴奏等音轨分离，全面对齐 MSST-WebUI。支持 BS-Roformer、Mel-Band Roformer、HTDemucs、MDX23C、SCNet、Bandit、Apollo、UVR 等模型（内置 29 个 vocal/multi 模型配置，模型在「模型管理」下载后即可用）
  - 推理参数无预设体系，改为**滑块调整**：分块大小 chunk_size（按秒）/ 重叠数 overlap / 批次大小 batch_size
  - 音频归一化开关、**启用 TTA**（推理时间约 ×3）、**输出音轨勾选**（不同模型可输出音轨不同，不勾选即全部）、**输出格式**（wav 默认 / flac / mp3）
  - **实时分块处理进度 + 剩余时间估算**（GPU 加速时接近实时完成）
  - **推理参数按模型保存 / 还原 / 应用预设**
- **通用 / 钢琴转录进度显示升级**：与音频处理面板一致，统一显示「处理 X% · 已用 · 剩余约」，实时反映进度
- **模型下载指示器改为全局顶部通知条**：5 秒无触碰自动向上收起为顶部细条（露出一点），鼠标悬停下滑显示进度，点击展开详细下载数据（逐项进度 / 速度 / 已下载，可取消），全程流畅动画
- **底部播放栏开合动画**：打开 / 收起重做底部滑入滑出 + 淡入淡出

## 改进
- 合并 v3.2.0 上游更新：歌单（SideBar/stores-app）与**声库 / UTAU**（engine_utau、main/utau.js、UtauLibrary、ViewVoicebank）采用上游版本；播放 / 音频 / 批处理管理器等按需整合
- 移除 demo 时代遗留的 demucs 分离路径，统一走更优的 MSST 引擎

## 更新方式
- 3.1.x 用户：应用内自动更新（增量更新器差分下载，只拉改动部分），或下载 `FuFumidi.Install.exe` 离线包覆盖安装
- 新用户：下载 `FuFumidi-Setup-3.2.0.exe` 完整安装
