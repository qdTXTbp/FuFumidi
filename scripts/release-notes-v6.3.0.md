# FuFumidi 6.3.0

## 编辑手感

- 钢琴卷帘点击/画音符即可试听。
- 多选拖动移动整个选区，按当前拍网格吸附；Ctrl 自由移动。
- 编辑后保持走带位置、循环区间和播放状态。
- 逻辑编辑器/宏改为修改前快照，撤销可回退。
- 编排片段进入播放；CC7/CC11、CC64 踏板、弯音进入内置合成器。
- 乐谱跨小节按 MusicXML 切片写 tie/tied。

## 标签页

- 可滚动 + 左右箭头 + 全部标签下拉。
- 固定/取消固定、分组色、右键关闭右侧、中键关闭、方向键切换。

## 界面与可访问性

- 六档界面材质：原生 / 玻璃 / 亚克力 / 云母 / 磨砂 / 天鹅绒。
- 第三方资源免责声明。
- 首页 FuMiVoice 手机版入口。
- 界面缩放单一来源；编辑器工具条可换行、去掉重复视图开关。
- 曲目/歌单/标签/菜单键盘化，27 个浮层补 dialog/menu 语义与焦点。
- 设置保存成功/失败真实反馈；可视化页无曲目空态。

## 稳定与体积

- 撤销 80 条 / 32MB 内存预算、动作标签、历史面板大小。
- 退出停止引擎 worker；设置写入合并+异步；storage/autosave 异步；主进程文件日志。
- 空 catch 补日志（367 处），CI 空 catch 门禁。
- 安装包 712MB → 596MB。
