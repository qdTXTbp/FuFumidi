# FuFumidi 6.6.2

本版做的是一条早先承诺过「之后更新再做」的用户反馈：
**XML 默认输出目录可配置** + **批量导出 XML**。

## 为什么以前「只看到转录结果的输出目录」

设置里原本就有一个「默认输出目录」(`output_dir`)，但它只被转录链路消费：
转录完成后按命名规则直接落盘，根本不弹保存框。而 MusicXML、MIDI、WAV
这些**手动导出**走的是另一条路 —— `main/dialogs.js` 里把保存对话框的
`defaultPath` 写死成系统的下载文件夹，PNG/PDF、音频、MP4、声库导出也各自
硬编码了同一个位置。所以无论设置里填什么，点「导出」都还是打开下载目录。

本版：

- 新增独立的设置项 **「导出默认目录」**（设置 → 功能），配输入框、浏览与清空；
  留空 = 系统下载目录。
- 新增 `main/export-dir.js` 作为**唯一决策点**：目录存在且确实是文件夹才使用，
  被删除、被改成文件、未填写或读取失败，一律安全回落到系统下载目录。
- 7 处保存对话框（MusicXML / MIDI / WAV / PDF / PNG / 视频 / 声库）统一接过去；
  选目录对话框也支持 `defaultPath`，第二次挑目录不用重新找。
- **故意不复用 `output_dir`**：一个管「转录结果自动落盘」，一个管「手动导出时
  保存框打开哪儿」，语义不同，分开设置互不影响。

## 批量导出 XML

乐谱页原来只有「导出当前这首」，曲库里的其它曲目又是懒解析的，
想导出十几首只能一首首点开、一首首选路径。

- 乐谱工具栏新增 **「批量 XML」**；曲库批量管理栏勾中曲目后也有
  **「导出 XML」** 入口，并自动预选已勾中的曲目。
- 弹窗里多选曲目、挑一次目录，即可整批导出 `.musicxml`；可选
  **整份总谱**（每声部一条 part）或 **每轨分谱**（每轨一个文件）。
- 文件名非法字符净化、大小写不敏感重名自动加序号；逐首显示进度，
  结束给出成功/失败汇总与失败明细。
- 可勾选 **「同时设为导出默认目录」**（默认开），下次导出直接沿用。
- 曲目按四级回退**只读**加载，不会循环 `selectSong`，
  因此批量过程中不会切换当前曲目、也不会打断播放。

## 升级说明

- 从 6.6.1 升级不需要重装内置 Python 运行时，也不影响 GPU 增强包。
- 已应用过热补丁的用户：本版完整包已包含此前所有引擎修复，
  启动后热补丁会自动更新到与本版一致的清单，无需手动操作。
- 已知边界：Tauri 分支的 `save_binary` 尚未读取该设置，
  Electron 正式安装包不受影响。

SHA256 与资产清单见 release 说明页。
