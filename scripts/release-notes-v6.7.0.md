# FuFumidi 6.7.0（正式版）

> 本版**合并了 beta 通道的全部改动**（6.7.0-beta.1 / 6.7.0-beta.2）。
> 之前把更新通道切到「测试版」的用户，会直接从 beta.2 升到 6.7.0 正式版；
> 正式版通道用户则从 6.6.3 升上来，同样收到以下全部内容。

这一版有四条主线：视觉地基（动效 + 圆角 + 运行时）、导出格式补齐、轨色全界面一致、
AMD 自检说人话；外加一个新的「卷帘」页签。

## 新增 · 「卷帘」页签

「音乐」分组现在是：演奏 / 可视化 / **卷帘** / 乐谱。

- 横轴时间、纵轴音高，**按 127 键全键盘定位**，换歌不会整体跳位；播放头居中跟随。
- 自带一套走带：开始 / 暂停（继续）/ 重置 / 重新播放，不影响播放栏。
- BPM 可填覆盖（只改预览快慢，不动工程）；横向 20–300 px/s、纵向 2–20 px、最短高亮 0.01–2 秒。
- **未播放的音符淡出成底图（30%），正在响的音符实色高亮并带一点辉光**，一眼能看出这一拍在响哪些音。

## 动效 · 全站改用阻尼弹簧参数

以前每个面板、按钮、弹层各自写 `duration + cubic-bezier`，回弹感不统一。
现在由一套阻尼谐振子参数（刚度 / 阻尼 / 质量）推导，阶跃响应采样成 CSS `linear()`，
浏览器端跑的是真实阻尼曲线；派生三档速度并回填旧 token，200+ 处过渡无需逐条改写。
参数入口 `frontend/src/core/motion.js`，`prefers-reduced-motion` 仍然强制关闭动画。

## 圆角 · 全部改为连续曲率

所有 DOM 圆角使用原生 `corner-shape: squircle`；头像、状态点、开关滑块等正圆元素保持 `round`。
Canvas 侧（卷帘音符块、编排片段、波形卡片、可视化图元）换成四阶超椭圆路径，与 DOM 观感一致。
不支持 `corner-shape` 的宿主自动退回普通圆弧。

## 运行时 · Electron 37 → 38（Chromium 140）

原生连续曲率需要 Chromium 139+。系统要求不变（Windows 10 1809+ / x64）。
覆盖安装即可，设置 / 曲库 / 工程路径不变，更新器与签名清单格式不变。

## 导出 · 新增 MP3 / FLAC / OGG

以前只有 WAV 三档，README 里写的 MP3/OGG 其实没实现。现在导出格式是 6 项：

- **WAV 16 / 24 / 32-bit float**（不变）
- **FLAC 无损**、**MP3 320 kbps**、**OGG Vorbis Q6**（新增）

渲染进程仍只产 24-bit WAV 母版，压缩格式由包内 ffmpeg 转码，最后走同一套原子落盘 + sidecar
校验清单。不联网、不新增依赖、不改变 WAV 导出行为。

## 编辑 · 轨道颜色全界面一致（issue #39）

同一乐器以前在不同页面可能是两种颜色（卷帘红 / 混音台蓝；Voice 土黄 vs 紫），
根因是两套调色板顺序不同。现在统一走 `palette.trackColor()`，并且跟随深浅主题；
超过 8 轨按 8 回绕。

## 加速 · AMD ROCm 自检说人话

安装完自检不再只看 `torch.version.hip`：

1. 读真实设备名与显卡架构（gfx）；
2. 真跑一次 256×256 矩阵乘并与 CPU 对拍；
3. 失败时直接说明「你的 gfx 不在当前包支持的 7 个架构里」，并建议先用 CPU。

> 本版**没有**新增 RX 6000/5000 支持 —— 它们的运行时需要 AMD TheRock 的 Windows 架构包，
> 尚未提供。本版只是让不支持的卡在安装时就说清楚，而不是转录中途崩。

## 升级建议重点看

1. **更新链路**：beta 用户从 beta.2 升 6.7.0、正式用户从 6.6.3 升 6.7.0，两条都要走一遍。
2. **卷帘**：长曲目（几千音符）拖动横向滑块、反复开始/重置，看是否跟手；深色主题下高亮对比是否够。
3. **导出**：MP3 / FLAC / OGG 各导一次，确认能播放、扩展名与内容一致。
4. **轨色**：卷帘 / 混音台 / 分析页 / 乐谱页对照同一条轨；切深浅主题再看一次。
5. **可视化 / 壁纸**：Chromium 138 → 140 的 WebGL 回归是最大风险点。
