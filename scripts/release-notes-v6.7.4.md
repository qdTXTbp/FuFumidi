# FuFumidi 6.7.4（视频背景与流畅度）

> 本版修复视频导出的瀑布背景，并优化首屏加载、页面切换和创作页页签切换。

## 修复 · 视频预览/导出没有瀑布背景

- 视频导出重新使用「音频瀑布」页的背景，不再使用另一套独立设置。
- Wallpaper Engine 视频工程直接读取工程源视频，预览和导出的 MP4 使用同一份背景。
- 修正旧版壁纸标题中的控制字符导致背景 JSON 整条解析失败的问题；重开应用后瀑布背景不会变空。
- 仪表盘模板删除，视频导出只保留「瀑布流」；半透明卡片让瀑布背景可以透出。

## 优化 · 首屏与页面切换

- 首屏主包从约 1.5MB 降到约 940KB；日文词典改为按需加载。
- 音乐、转换、可视化、转码等常用页面在空闲时预取分包。
- 创作页五个功能页保留缓存，切换时不再反复挂载/销毁重页面。
- 路由与创作页页签动效改为中间档，保留反馈但减少等待。
- 转换页没有选中曲目时不再提前解码 4K 瀑布视频。

## 升级后请验

1. 转换 → 视频导出，预览背景应来自「音频瀑布」页；
2. 导出 MP4 的背景应与预览一致；
3. 完全关闭应用再打开，瀑布背景仍然保留；
4. 创作页转录/转换/变谱/翻唱/调教切换应跟手，不应出现旧页面卡住。

## 说明

- 本版是完整安装包更新；修复位于 `app.asar` 内的 renderer 代码与 `index.html` 的媒体 CSP。
- 背景文件仍沿用「可视化」页的设置；应用整窗壁纸与瀑布背景相互独立。
