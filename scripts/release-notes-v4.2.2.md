# FuFumidi v4.2.2

一条修复，针对「用久了 C 盘莫名被吃掉几个 GB」。

## 修复

### 引擎临时文件不再堆积
- 转码音频时会把整首歌解码成 WAV 落到系统临时目录（单个文件上百 MB）。
  正常结束时都会删掉；但**进程被强杀**（取消转录 / 超时 / 崩溃）时，
  清理语句不会执行，文件就一直留在那里 —— 实测一台机器上积了 **12 个共 1.34 GB**
- 现在引擎每次启动会兜底回收系统临时目录里本应用遗留的临时文件与目录
  （`midi_tool_*`，且超过 6 小时的），并打印 `[清理] 回收 N 项`
- 6 小时阈值是保守取值：同一时刻可能有多个引擎进程在跑，只回收「明显过期」的，
  不会误删正在使用的文件

## 升级说明
- 增量更新：设置 → 更新 → 检查更新（走 ghfast 镜像，仅下载改动部分）
- 全新安装：运行 `FuFumidi Setup 4.2.2.exe`
- 之前几次异常退出留下的残留：升级后第一次转录时会被自动清掉；
  手动清也行，删 `%TEMP%\midi_tool_*` 即可
