# FuFumidi 6.1.3

## 转录队列：运行中可切换视图 · 顺序转录 · 每日队列产物歌单

- **运行中可切换队列**：切换只改变正在查看/编辑的队列，不打断正在转录的队列；运行队列带「▶ 正在转录」标记并锁定设置。
- **依次转录全部队列（默认关，用户显式开启）**：按队列顺序，一个队列跑完自动接着下一个；每个队列用自己的模型/参数/产物歌单。
- 暂停/取消作用于整条链；运行中新建队列仍允许（当前批次结束后可切过去）。

## 降噪选项回来了

- 高级参数新增「转录前降噪」：关闭（默认）/ 轻降噪（谱减）/ 强降噪（UVR-DeNoise 模型）。
- 默认关闭保证旧输出逐音符不变；日志不再在未降噪时出现「降噪=」字样，改为「电平归一（降噪关闭）」。

## 每模型推荐识别片段长度

- 预设内置推荐值：Basic Pitch 0（模型窗固定 2s，不额外切段）、MuScriptor 5s（训练块长）、钢琴 10s、Aria-AMT 30s、Transkun 16s。
- 界面滑条标注「推荐」；偏离训练块长会改变边界上下文，MuScriptor 还可能造成跨块音色漂移。

## 显存策略 / 速度

- GPU 信息显示显存空闲/总量；新增「显存策略」：自动 / 低显存模式（自动降批，推荐）/ 允许借用系统内存。
- 低显存模式从源头降低批大小，尽量避免 Windows 驱动静默借用内存（溢出会慢 5–10 倍）；内存无法达到显存速度。

## P2 补充

- 显存策略面板显示 NVIDIA 驱动版本、VRAM 空闲/总量、共享显存回退支持状态（驱动 ≥536.40；≥546.01 可按应用关闭）。
- MuScriptor 新增「音色稳定后处理」（默认开）：把短命、孤立的乐器轨并入邻近主导轨，减少分块边界「同一旋律换音色」；可关闭。
- 高级参数新增「运行统一内存实验（CUDA Managed Memory）」：验证 cudaMallocManaged 可用性与分配/主机写入/同步耗时；仅实验，不改变 PyTorch 转录分配器。
## 音色稳定预设（A/B 后固化默认）

- 新增 **MuScriptor · 音色稳定** 预设：固定 5s 块 + 跨块延音缝合 + `instrument_probe` 预分析锁定主乐器组 + 短命孤立轨后处理。
- A/B（30s 双音色合成 / 钢琴 fixture，medium，2 次取第 2 次）：双音色素材换音色证据 5 → 0、F1 0.4914 → 0.7692、峰值显存不变；钢琴素材 F1/显存持平（多约 0.2–0.4s）。
- 已把 MuScriptor 三规格默认预设固化为「音色稳定」；仍可手动切回「最优」（不预分析/不硬约束）。详见 `docs/plans/2026-10-18-muscriptor-preset-ab.md`。
## 批量队列速度

- MuScriptor 在 GPU 环境复用已加载模型：同一队列的后续曲目跳过模型加载（实测 8s 素材第 2 首 5.66s → 1.45s；30s 素材模型加载约占每首固定开销 2–3s）。
- 低显存模式不启用缓存（优先保证不 OOM）；CPU 也不缓存（多 worker 各留一份模型易爆内存）。
- 转录慢的常见原因：自动 BPM、节拍网格检测、稳定预设的预分析都是每首额外固定开销；不需要时可在高级参数关闭。
## 探测与空 MIDI 修复（2026-10-20）

- 自动探测模型按主模型规格选择：large → 独立 small 探测器（探测从数分钟降到几秒级）；medium/small → 主模型探测。
- 新增 0 音符保护：识别结果为空时先取消乐器组约束重试一次，仍为空则报错并附音频/模型/限制信息，不再静默生成 33B 空 MIDI。
- 排查记录：`docs/plans/2026-10-20-empty-midi-probe.md`。
## 分段探测与图标修复（2026-10-20）

- 新增 MuScriptor「分段探测乐器组（实验，默认关）」：30/60s 分段 + 独立 small 探测器 + 全局/邻段并集约束；A/B 报告见 `docs/plans/2026-10-20-segment-probe-ab.md`。
- 修复 MIDI 文件图标：打包版启动时按设置自愈 `.mid/.midi` 关联，图标指向 FuFumidi.exe 自带 logo；开发版不再写 Electron 图标。
## 自动探测改用专用音频标签模型（方案 B）

- 内置 `resources/models/audio-tagger`（AudioSet zipformer-small int8 ONNX，26MB），自动探测/分段探测不再占用主模型；CPU 推理约 0.3s/10s。
- 置信度不足时宁可不锁定（日志会说明），避免硬约束把真实乐器关掉；MuScriptor 探测器保留为模型不可用时的回退。- 置信度不足时自动回退 MuScriptor-small 探测（日志会标注），保证音色稳定不会变成空操作；标签模型自身只占 CPU、不占主模型。

## 自动探测：专用音频标签模型（方案 B）

- 新增内置 AudioSet zipformer-small 标签模型（`resources/models/audio-tagger`，int8 ONNX，26MB）：自动探测/分段探测不再占用主模型，CPU 约 0.3s/10s。
- 标签模型置信度不足时自动回退 MuScriptor-small 探测（日志标注），避免「音色稳定」在真实混音上变成空操作；标签模型不可用时也保留回退。
- 分段探测继续为实验开关（默认关）；A/B 见 docs/plans/2026-10-20-segment-probe-ab.md。
