## 概述

本轮是 v5.0.1 之后 **123 个提交**的合集，主线三条：**调教（歌声合成）补齐渲染路线与多说话人**、
**转录从"能跑"变成"可调 + 可复现"**、**资源中心与安装/更新体验重做**。
另修掉 22 个缺陷，并把 6 条"想当然的结论"用实测改正（见第七节）。

---

## 一、调教（歌声合成）

### 1. Worldline v11（R1.1）开箱即用

hnsep 谐波/噪声分离照搬上游 C# 实现，补齐三个原生绑定，
`useHnsep` / `HnAnalysisF0In` / `SynthContinuousNoise` 整条链路接通。
资源中心现在可以直接下载 `hnsep_240512`（自建 CNB 镜像，实测真包验证），
模型落到数据根即可用 —— 选 v11 不再需要手工装配。

### 2. Worldline v20（R2）—— 第三条渲染路线

WORLD 特征 → `mel.onnx` → 128bin/512hop 通用声码器 → 波形。
mel 模型**随包**（85,404 B），所以 v20 不需要额外下载模型；
声码器用资源中心已有的「NSF-HiFiGAN 通用声码器」。
补帧（左补 4 帧并补到 16 的倍数）、`ap` 补 1、出波形后裁掉补帧、首尾各 512 样本淡入淡出
—— 全部逐行对齐上游 `WorldlineRenderer.cs:138-193`。
轨道渲染器下拉新增「Worldline v20（最新，需通用声码器）」。

### 3. DiffSinger 多说话人

多说话人声库的检测、`.emb` 文件体检、上游 `SpeakerEmbedManager` 的移植、
嵌入接进推理输入、**音符级说话人优先 / 轨级默认回落**、以及界面上的说话人选择。
单说话人声库的行为完全不变。

### 4. 其它

- **通用声码器覆盖**接通界面，并进缓存键（换声码器不再命中旧缓存）
- **GPT-SoVITS 采样三参数**（`top_k` / `top_p` / `temperature`）可调；
  默认**不发送任何采样参数**，保持"没有意见"的原始行为
- 上游移植 5 项：flag 表达式表按快照缓存、resampler 清单的额外元文件、
  preutter 上限放宽到文件开头（调教正确性）、同名外部 resampler 不再顶掉内置、
  DirectML 串行区（防原生层杀进程）

## 二、转录

- **模型选项接到界面**：Basic Pitch / 钢琴 / MuScriptor 的参数（导出速度、最高音高、
  超长音符上限、合并重叠、力度归一化、`prelude_forcing`、`temperature`、`cfg_coef`、
  `beam_size` 等），并补上 `max_freq` 漏掉的那一跳
- **计算精度开关** fp32 / bf16 / fp16（默认 fp32）。实测**两个后端都没有提速**，
  所以它不是提速档，只是留作实验开关 —— 文案里已写明
- **删任务模板 + 多队列**：每个队列自带模型与参数
- **多条弯音曲线**（`multiple_pitch_bends`）全链路转发
- **回放台**：token 流边生成边落盘，可 `--replay-tokens` 复现 ——
  148 分钟的长跑只要 19.5 秒就能复现一次，MIDI **逐字节相同**
- GPU 真实路径实测 **34.6 分钟**（比实时快 3.5 倍）；安装版本自带可用的 CUDA 包

## 三、资源中心与界面

- **两级分类**：顶层「调教」，下设声库 / 音色 / 调教模型
- **卡片顶置 · 拖拽排序 · 标签 · 按标签作者搜索**（四页通用；分类视图里同样可拖）
- **预设按模型归属**：每个模型一套最优预设，切模型自动套用，用户绑定可记忆；
  预设落点迁到数据根并做了一次性迁移
- **UTAU 声库扩充 + 本地导入入口**，声库页与 DiffSinger 页统一模板
- **NumSlider**：所有参数滑块都可以直接输入数值（39 处）
- **全局体检**：一键采集 + 判定 + 脱敏报告，可直接粘贴进 issue；
  含各后端（CPU / CUDA / DirectML / XPU）的算力实跑校验

## 四、安装 / 卸载 / 更新

- **更新页新增「线路测速」**：列出当前通道下每条线路的**延迟（首字节）与速率**，
  标出最快的一条，可一键设为首选线路。
  每条线路只取 256 KB 就断开，不会下载整个安装包；
  首选线路只是"提到最前"，不可达时仍按回退链自动换源。
  另外校验首块必须是 `MZ`（PE 头）—— 镜像返回 200 却塞了拦截页时会被判失败。
  本机实测：CNB 783 ms / 1.56 MB/s，ghfast 4886 ms / 0.09 MB/s，GitHub 与 ghproxy.net 不可达。
- **安装器外观**：NSIS 侧栏与页眉品牌图（代码绘制）。
- **卸载改为真正的选择页**（不再是弹窗）：默认选中「保留我的数据」，
  写明数据位置与不可恢复性；静默卸载仍按保留处理。

## 七、把之前说错的结论改正了

- **bf16 提速**：先说 +43%，大样本复测是 **0%**（GPU 上 0.6%）；惰性 conditions 实测
  0.01 s 根本不在关键路径；SDPA 上游早已使用 → 提速梯队 1 结项：**无可交付加速**
- **「GPU 要 148 分钟」**：那是裸跑基础运行时的数字；安装版本自带 CUDA 包
  （torch 2.9.1+cu128，实测 `cuda=True`），真实路径 34.6 分钟
- **v20「两个不能做的理由」全被证伪**：mel 模型就在上游仓库里，声码器本来就有
- **长音频尾部异常**：定性为**设备侧热劣化**（冷机差 7.1 倍），不是代码尖峰
- **上传慢的根因**：Python `requests` 静默走系统代理，不是链路物理上限
