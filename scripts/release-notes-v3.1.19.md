# FuFumidi v3.1.19

## 修复
- **应用内更新不再报「正在被另外一个程序使用中」**：此前拉起增量更新器后主程序不退出，FuFumidi.exe 被自身进程锁定，更新器无法替换文件而中止。现在拉起更新器后主程序自动退出（先返回提示），释放文件锁，更新器正常替换、完成后自动重启
- **安装器不再反复提示「有之前没清理的目录 / 覆盖重装」（根治）**：根因是同一应用曾以不同权限/作用域安装过，会在 HKCU 与 HKLM 各留一条卸载注册记录，electron-builder 安装器误判为「同时存在 per-user 与 per-machine 安装」而反复提示覆盖。现在安装器在启动最早阶段（preInit）自动清理所有作用域的历史卸载项，安装永远从干净状态开始
- 附带：3.1.18 的完整性检查 core-corrupt 误报根治（original-fs 读真实文件大小）保持生效

## 更新方式
- 3.1.x 用户：应用内自动更新（增量更新器差分下载，只拉改动部分），或下载 `FuFumidi.Install.exe` 离线包覆盖安装
- 新用户：下载 `FuFumidi-Setup-3.1.19.exe` 完整安装
