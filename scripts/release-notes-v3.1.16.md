# FuFumidi v3.1.16

## 修复
- **一键修复/自动更新不再中途中止**：此前从应用内触发修复时，应用未退出就拉起安装器，安装器检测到 FuFumidi.exe 占用会报「进程未关闭」并中止。现改为先让应用自我退出 → 守护脚本确认主程序完全退出 → 再静默安装 → 校验完整 → 重启，完整走完修复/更新
- **完整性检查 core 误报修复**：新增 asar 文件头校验（杜绝体积足够但内容截断的漏判）+ statSync 重试（规避安装器替换文件瞬间误报 core-corrupt/core-missing）

## 更新方式
- 3.1.x 用户：应用内自动更新（或下载 `FuFumidi.Install.exe` 离线包覆盖安装）
- 新用户：下载 `FuFumidi-Setup-3.1.16.exe` 完整安装
