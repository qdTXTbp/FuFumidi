# FuFumidi v3.2.4

## 修复
- 修复大音色（GeneralUser / FluidR3 等）播放大 MIDI 时打开乐谱导致音质劣化 / 噪点爆破的问题：主线程被乐谱渲染占住时，SF2 音符的定时触发会成簇同时发声，现对明显过期的音符跳过触发，消除音头聚簇爆音
- 修复下载新音色库后需重启才能启用的问题：切换音色前先恢复 AudioContext 运行态，启用失败自动重试一次；确属无法加载时提示可重启后再试
- 修复 Aria-AMT 运行时依赖安装失败（“unknown”）：从 GitHub 安装 amt / aria-utils 改为走 gh.jasonzeng.dev / ghfast.top / gh-proxy 多个镜像自动回退，每个源 600s 超时即切换，不再因直连卡死而无提示
- 修复首页功能区两个重复的「资源中心」卡片：其一改为「新手引导」入口
- 修复新手引导全功能实操第一步失效（首页卡片改名后指向不存在元素）

## 更新方式
- 3.2.x / 3.1.x 用户：应用内自动更新（增量更新器差分下载），或下载 `FuFumidi.Install.exe` 离线包覆盖安装
- 新用户：下载 `FuFumidi-Setup-3.2.4.exe` 完整安装
