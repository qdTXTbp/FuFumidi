# FuFumidi 6.3.1

## 编辑器

- 选区上下文工具条：移调 ±1 / ±12、力度 ±、量化、克隆、删除。
- 大工程 LOD：缩小时省略轻力度音符，选中与编辑轨始终保留。
- 转录结构体检：音符/轨数/时长/长音/最大同时发声，一键载入校对。
- 长音修复：超过 15 秒的音符一键截断并写回 MIDI。
- MPE 弯音：音符级 ±12 半音弯音编辑。
- 转录校对：试听原音频。
- 模型提示：Large 1.3B 耗时警告，速度优先建议 Medium。
- 编排参考音频轨（试听从播放头开始）；乐谱双击定位到编辑器。
- 转录 AB：试听原音频与转录 MIDI。
- 编排片段静音（comping 最小子集）；WE 预览图导出。
- VST3 渲染队列。

## 门禁

- UI token 审计 0 基线：颜色、字号、圆角、间距。
