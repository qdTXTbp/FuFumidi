# FuFumidi 6.1.0

> 翻唱路线重大更新：**RVC 变声**正式可用 —— 导入模型即可把原唱换成目标音色。

## RVC 翻唱（本次主更新）

- 翻唱流程改为：**分离（可选）→ 变声（RVC）→ 混音**。旋律、节奏、咬字都来自原唱，不需要歌词；GPT-SoVITS 逐句重合成路线退役。
- 模型导入三种形态：**选文件夹**（登记引用、不复制）/ **逐个选文件**（按扩展名自动归类 .pth/.pt、.index、.yaml）/ **导入 zip**；翻唱页与「模型管理 → RVC 模型」都能导入，导入后可「校正」读取权重真实的版本 / f0 / 采样率。
- **人声分离改为可选**：默认「不分离 —— 变声整曲」，不需要任何分离模型；要用分离时在下拉里自选已下载的模型（先分离再只变声人声，最后与伴奏混音）。
- 推理照搬 RVC 官方仓库（`engine/rvc/vendor/rvc/`，MIT，一行未改）：30k/40k 老版权重与 48k v2 都支持。
- 长曲自动按低能量点切块推理再混音，支持断点续跑（中断后继续，或勾选「不复用上次结果」全部重算）。
- 应用**不内置、不代下载** RVC 模型（社区权重 CC-BY-NC-4.0：禁商用、须署名训练者），请自备。

## 其他

- GPU：修掉主进程启动即崩的死导出；加速包文件名 svc/rvc 两种拼写都识别。
- 翻唱页常驻模型导入行：不用跳去模型管理页即可导入。
- 长任务看护：无进展超时（idleTimeout）替代总时长超时，长音频分离/翻唱不再被误杀。

## 已知限制

- `kind=rvc` 推理包（torch + faiss + HuBERT/rmvpe 权重）需在「工具 → GPU 加速包」安装；未安装时引擎会如实提示缺什么，不会产出假成品。
- DDSP-SVC（.sf_pkg 封装）暂不支持。
