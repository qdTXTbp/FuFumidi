# FuFumidi v3.2.1

## 修复
- **音色工坊大音色无法启用**：修复 FluidR3（约 141MB）等大体积音色「能下载却无法启用」的问题。此前 JS 合成器加载上限仅 64MB，与主进程读取上限（512MB）不一致导致大音色一律被拒载；现放宽至 512MB，FluidR3 / Arachno / SGM 等店内可下载音色均可正常使用
- **音色加载反馈优化**：启用 / 试听大音色时显示「正在加载」遮罩（首次解析大音色需占用主线程几秒）；若加载失败会回退到默认合成器并弹出具体原因，不再出现「显示已启用、实际未加载成功」的假象

## 更新方式
- 3.2.0 / 3.1.x 用户：应用内自动更新（增量更新器差分下载，只拉改动部分），或下载 `FuFumidi.Install.exe` 离线包覆盖安装
- 新用户：下载 `FuFumidi-Setup-3.2.1.exe` 完整安装
