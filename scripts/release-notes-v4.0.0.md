# FuFumidi v4.0.0

本次更新带来 **云同步**：把歌单与 MIDI 曲目备份到云端，并与手机端 FuMiVoice 互相同步。

## ☁️ 新增：云同步

- **邮箱注册 / 登录**（注册与登录均需通过人机验证）。账号与存档放在 Cloudflare：关系数据走 D1，MIDI 文件体走 R2。
- **手动「立即同步」前先选存档**：弹出本机与云端各自的规模（曲目数 / 歌单数），由你决定以哪一份为准；选择后另一份会被覆盖。
- **首次在新设备登录**时，若本机与云端都有存档，同样会列出两侧规模让你选择保留哪一份。
- **侧边栏右下角显示当前账号**（未登录显示「未登录用户」），点击即可登录 / 注册 / 退出登录，全程带过渡动画。
- **与手机端 FuMiVoice 双向同步**：以文件名作为曲目标识，歌单里的曲目引用在两端都能还原；删除会作为墓碑传播到其他设备。

## 🛠 修复

- **大批量曲库同步中途失败**：此前几百首曲目会一次性上传 / 下载，请求体与响应体过大而被中途打断（实测 526 首只成功 121 首）。现改为「元数据一次同步 + 歌曲字节分批传输」，每批 6 首。
- **歌单结构没有上云**：云端歌单表始终为空，手机端看不到「哪首歌在哪个歌单」。原因是同步读的是本地 SQLite 备份，而界面实际使用的歌单数据在别处；现已改为以界面真实数据为准。
- **部分曲目只有信息没有内容**：本地记录缺 MIDI 字节时仍照发元数据，云端出现「有曲目、无内容」的空壳。现在缺字节会从本地缓存补取，确实取不到的会**明确提示**并跳过，不再静默生成空壳。

## 📦 安装与更新

- 3.4.0 及以下用户：应用内「检查更新」增量升级（推荐，只下载改动部分）
- 完整安装包：`FuFumidi-Setup-4.0.0.exe`

> 云同步是可选功能：不登录、不点同步时，应用依然完全离线运行，转录与编辑不上传任何数据。
