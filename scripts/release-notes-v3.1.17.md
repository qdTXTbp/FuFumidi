# FuFumidi v3.1.17

## 修复
- **完整性检查 core-corrupt 误报（彻底修复）**：全新安装/更新完成后启动，偶发弹出「完整性检查发现以下问题 · core-corrupt app.asar」。原逻辑只采样一次文件大小，安装器/更新器替换 `app.asar` 采用「写临时 → 删旧 → 改名」，检查恰逢文件仍在写入、尚未落盘时，读到的小体积（<1MB）会被误判为损坏。现改为先等待文件**落盘稳定**（连续采样大小一致）再校验，最多等待约 1.5s，仍异常才提示修复——写入中不再误报，且真损坏仍会被可靠检出

## 更新方式
- 3.1.x 用户：应用内自动更新（增量更新器差分下载，只拉改动部分），或下载 `FuFumidi.Install.exe` 离线包覆盖安装
- 新用户：下载 `FuFumidi-Setup-3.1.17.exe` 完整安装
