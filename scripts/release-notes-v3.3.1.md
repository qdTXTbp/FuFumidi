# FuFumidi v3.3.1（热修复）

修复 v3.3.0 升级后「资源中心 → 模型管理」转录模型无法下载的问题。建议 3.3.0 用户尽快更新。

## 🛠 修复

- **转录模型无法下载（报 ENOENT）**：安装器更新会整体替换内置模型目录（`resources/models`），此前指向该目录的 junction 变成断链，导致下载建目录时报 `ENOENT: no such file or directory, mkdir ...models\aria_amt`。现启动时与每次下载前自动清理断链占位，模型正常落盘用户目录
- **内置小文件模型不再依赖 junction**：basic-pitch 量化模型等改为随迁移复制到用户目录，升级替换内置目录后依旧可用

> 3.3.0 的全部功能（专业音效调节 / 播放模式与无缝播放 / 智能音乐库 / 托盘后台播放 / 并行转录 / 乐谱零重刻等）保持不变。

## 📦 安装与更新

- 3.3.0 用户：应用内「检查更新」增量升级（推荐）
- 完整安装包：`FuFumidi-Setup-3.3.1.exe`
