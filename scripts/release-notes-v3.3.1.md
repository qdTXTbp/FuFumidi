# FuFumidi v3.3.1

本次更新聚焦**转录提速**与一批体验修复。建议所有 3.3.0 用户更新。

## ⚡ 提速：MuScriptor GPU 批量推理

长音频转录此前在 GPU 上仍是「分块串行」，GPU 大部分时间在等数据，利用率只有约 68%，速度上不去。本次改为 **GPU 批量推理**：

| 指标 | 修复前（最高质量·串行） | 修复后（均衡·批量） |
|---|---|---|
| 120 秒音频耗时 | 57.2s | **25.0s** |
| 实时倍率 | 2.09× | **4.78×** |
| GPU 占用 | 约 68% | **约 90%** |
| 1 小时歌曲预计 | 约 65 分钟 | **约 25 分钟** |

- **GPU 机器默认推荐「均衡」档**（批量推理）；想要极致 chunk 边界质量仍可手动选「最高质量」
- 批量大小按显存规格自适应（small / medium / large 分别设上限），显存不足时**自动降级重试**，不会转录失败
- CPU / DirectML 环境自动保持串行（批量在非 CUDA 设备无收益）

## ✨ 新增

- **低音增强开关**（通用识别）：关闭主旋律强化（melodia trick），旋律密集时不再丢贝斯 / 低音声部
- **GPU 加速安装可取消**：安装/下载过程中可随时取消，自动清理半装文件；同时 pip 增加重试与本地缓存，网络抖动不再前功尽弃

## 🛠 修复

- **导入歌曲打断播放**：播放中导入 MIDI 只入库、不再切换到新曲（也就不再停止当前播放）
- **钢琴卷帘滚轮方向相反**：向下滚动现在看到更低音，符合直觉
- **新手引导遮挡内容**：「全功能实操」引导时整页被磨砂模糊、虚线框内目标看不清，已移除遮罩模糊
- **和弦分析更全面**：由只认大三/小三和弦，扩展为七和弦（maj7 / 7 / m7 / m7b5 / dim7）、挂留（sus2 / sus4）、增三/减三，并支持**转位**（如 C/E、G7/B）
- **播放列表双击播放**：左侧列表双击即可切歌并开始播放
- **转录进度不匹配**：进度条改为引擎**真实分块进度**，不再长时间停在 3%；并去掉「已用」旁重复的「转录中 3%」文字
- **GPU 安装进度浮层关不掉**：右下角浮层现在可收起（后台任务继续，设置页仍可查看进度与取消）
