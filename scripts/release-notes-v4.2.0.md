## 优化

### 流畅度：修复大 MIDI 下的全应用卡顿
- **根因 1** `PianoRoll`：演奏页全曲概览的可视窗口是整首歌的 60%，加载 9 万+ 音符的 MIDI 时每帧约 22 万次 `fillRect`；且被 KeepAlive 保活，离开演奏页后仍满帧空转
- **根因 2** `ViewLyrics`：时间轴每帧重建「全曲音符数组」（9 万元素）并逐个绘制
- **根因 3** `EditorCanvas` / `ViewEdit`：绘制循环无条件每帧重绘，且每帧调用 ~30 次 `getComputedStyle`
- **根因 4** KeepAlive 保活泄漏：`ViewLyrics / ViewViz / ViewScore / PianoRoll / EditorCanvas / ViewEdit` 的循环都没有停止机制（`onDeactivated` 只对被缓存组件的根触发，嵌套组件需用尺寸归零判定可见性）
- **根因 5** 高刷屏 rAF 跑到 300fps，连续重绘比预期贵 5 倍
- 统一改为「按需重绘 + 静态层离屏缓存 + 可见性门控 + 60fps 限流」。实测各页空闲绘制量：

  | 页面 | 修复前 fillRect/秒 | 修复后 |
  |---|---|---|
  | 曲库 | 2,648,822 | 0 |
  | 编辑 | 3,973,312 | 0 |
  | 歌词 | 189,840 | 0 |
  | 演奏 / 乐谱 / 首页 / 资源 | 后台空转 | 0 |

### 编辑视图布局
- 工具栏统一 26px 基准高度（原先分段控件 30px、按钮 26px、分隔线 20px 三种混排导致错位）
- 「更多」高级面板改为**悬浮分栏卡片**：11 个分组卡片，标题独占一行、控件统一 22px，展开不再挤压钢琴卷帘、也无内滚裁切
- 移调组（±1 / ±8）收进「更多」面板，工具栏在窄窗口下不再横向溢出

## 多语言
- 补齐 272 条界面文案的**英文**与**日文**（渲染端中文文案覆盖率达到 100%）
- 修复繁体单字表缺失的 **264** 条常用映射（此前繁体下会残留简体，如「再分**发**」「版**权**声明」）
- 统一日文术语：声库一律译作「音源」，与既有词表一致
- 修正中文语境里误用的日语/繁体字形（単 → 单、擴 → 扩）

## 其他
- 版本号统一为 4.2.0（package.json / 打包产物内 asar）
- 内置环境与依赖随包分发：`resources/python`（内置 Python 运行时）、`engine/`（含 engine_utau）、`resources/rust-core`（Rust 核心 fufumidi-core 0.2.0）
- 数据目录 `FuFumidiData` 仍受更新器保护（`Build/kachina.config.json` 的 `ignoreFolderPath`），应用内更新不会删除模型/声库/音色库

## 升级说明
- 增量更新：设置 → 更新 → 检查更新（走 ghfast 镜像，仅下载改动部分）
- 全新安装：运行 `FuFumidi Setup 4.2.0.exe`
- 首次启动会自动把旧位置（C 盘用户目录）的模型/声库/音色库迁移到 `<安装目录>/FuFumidiData`，带进度提示
