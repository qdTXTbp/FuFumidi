# FuFumidi 6.2.4

发布于 2026-10-24。本版是 6.2.3 后的界面与长任务修正，安装包与增量更新均包含完整离线引擎。

## 任务中心

- 修复悬浮球被拖到窗口边缘外后点击无效；启动时按当前窗口重新限制位置。
- 转录、分离、导出等长任务登记到任务中心，打开即可看到进行中任务、进度和取消。
- 悬浮球仍支持拖动、贴边隐藏、持久化位置。

## 乐谱

- PNG 导出改为白底黑谱，不再使用应用深色背景。
- PDF 改为独立白底 A4 谱面页合成，不再把侧栏、播放条等深色 UI 打进 PDF。
- 分页预览重做：A4 比例分页、白底黑谱、单页查看 + 缩略图翻页、自动过滤空白页。
- MusicXML 导入导出逻辑保持。

## 音符瀑布背景

- 设置整体移入「外观 → 壁纸」功能区，不再独立成块。
- 壁纸库增加「应用目标：整窗壁纸 / 音符瀑布背景」切换。
- 同一个壁纸库内的图片、动态壁纸、在线静态、本地文件夹、直链都可直接应用到瀑布。
- 不再弹出旧的「音符瀑布动态壁纸」独立弹窗。
- 外观里仍保留瀑布背景的主题 / 纯色 / 图片 / 动态壁纸 / 透明、模糊与暗化设置。

## 资源页

- 五个页签统一为带图标的分段控件：模型管理 / 音色工坊 / 资源管理 / 存储治理 / 插件中心。
- 激活态、未激活态、图标间距和工作台页签一致。

## 包含 6.2.1 内容

- 插件中心移入资源中心并重做商店、已安装、日志与安装确认界面。
- 转录队列可独立滚动，运行面板不重叠。
- 顶栏曲目标签按内容宽度、折叠、右键分组。
- 任务小球拖动 / 贴边隐藏。
- 音效默认全 100%。
