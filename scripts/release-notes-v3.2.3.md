# FuFumidi v3.2.3

## 新功能
- **音色工坊新增 SGM-V2.01**：内置备受好评的高品质多采样 GM 音色，细节丰富、动态自然，可在资源中心 → 音色工坊一键下载
- **转录音频处理支持 VR（修复）模型**：音频处理模块的模型选择里新增「修复·VR」分类，可选用 UVR-VR 类模型进行修复 / 分离

## 改进
- **毛玻璃（Glassmorphism）补齐**：混音台、模型管理抽屉/弹窗、音频处理模型选择、参数预设管理等浮层统一为毛玻璃质感，与全局风格一致
- **浮层开合动画补齐**：顶栏菜单、乐谱「显示」下拉、UTAU 右键菜单、音色加载遮罩等均增加顺滑的进入/退场动画
- **大 MIDI 性能优化**：播放与编辑的钢琴卷帘按视口二分裁剪绘制，大文件加载后平移/缩放不再卡顿

## 修复
- 修复混音台点击无法弹出的问题（播放条毛玻璃会创建 fixed 包含块，弹窗改为挂载到 body）
- 修复音色文件与内置合成器节奏不一致 / 部分音色延迟高的问题：SF2 音符改为按绝对时间精确调度
- 修复曲目切换大文件时的交互延迟

## 更新方式
- 3.2.x / 3.1.x 用户：应用内自动更新（增量更新器差分下载），或下载 `FuFumidi.Install.exe` 离线包覆盖安装
- 新用户：下载 `FuFumidi-Setup-3.2.3.exe` 完整安装
