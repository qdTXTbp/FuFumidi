# FuFumidi v4.4.1

这一版只修 4.4.0 引入的两个缺陷，没有新功能。

## 修复

- **「设置 → GPU 加速」里预打包增强包的 CUDA 分卷下载不了**。点「下载并安装」会立刻失败并报
  「An object could not be cloned」。原因是分卷清单（每个分卷的地址与体积）在传给主进程时，
  仍然带着界面的响应式代理对象，而跨进程传输用的是结构化克隆 —— 代理对象无法克隆，
  于是请求还没离开界面就被拒了，主进程那边什么都没收到。

  DirectML 包不带分卷清单，所以完全不受影响，这也是它此前只表现为
  「CUDA 分卷下不动、DirectML 正常」的原因。

- **使用「下载源 = 国内 / 自动」时收不到更新提示**。发布流程在把资产镜像到 CNB 时，
  没有把 CNB 的版本锚点指向新发布的正式版（CNB 的锚点不是自动取最高版本号，而是 release
  上的一个标记）。而应用在国内源下，正是读这个锚点来判断有没有新版本 ——
  于是版本号会一直停在旧版，既收不到更新提示，也不会有任何报错。
  现已修正，且重跑一次镜像脚本即可自愈。

## 升级说明

- 应用内更新：设置 → 更新 → 检查更新
- 全新安装：运行 `FuFumidi Setup 4.4.1.exe`
- 本版不涉及安装 / 卸载与数据目录结构，升级不会动你的曲库、模型、声库与设置。

> **从 4.2.2 或更早版本升级时请注意**：更新完成后请**手动重新打开一次 FuFumidi**。
> 自动重启是由「发起更新的那一版」驱动的，而旧版的重启逻辑本身是坏的（守护进程压根没被执行），
> 没法反过来修好这一次升级的过程。更新本身是成功的 —— 文件已替换、数据完好，
> 关掉更新器窗口后手动打开即可。**从 4.3.0 或更新版本升级不受此影响。**
