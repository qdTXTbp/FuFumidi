# FuFumidi v5.0.0-beta.1

**5.0 大版本**的第一个内测版。主题：**UTAU 与 DiffSinger 真正融合**、**OpenUTAU 式可视化编辑**，
以及让谱面上画的音高曲线真正参与发声。

> 这是测试版（prerelease），仅「设置 → 更新 → 测试版通道」开启的用户可收到。
> 4.5.0 的功能已并入本大版本，不再单独发布 4.5.0 正式版。
> 参与内测前，请先从正式版升级到带双通道的版本。

## 新功能

### 统一声库选择器 —— UTAU 与 DiffSinger 在同一工作台融合

- 「制作音频」工作台顶栏改为**统一声库选择器**：可在 **UTAU 声库**与 **DiffSinger AI 声库**之间一键切换，
  选好声库点渲染即自动分流到对应引擎（UTAU 走拼接合成，DiffSinger 走 AI 推理），无需换页。
- 与 OpenUTAU 的架构思路一致：**融合做在渲染器/音素化器抽象层，而不是维护两套编辑器**。
- 切换引擎时若新引擎下已有可用声库会自动选中第一个；重进页面时引擎开关会依据已选声库自动回推，不会错位。
- 制作声库仍只允许常规 UTAU 声库（导出声库为 oto.ini 音源库）；AI 声库统一从
  「资源中心 → 模型管理 → DiffSinger 声库」下载。

### OpenUTAU 式谱面编辑（DiffSinger 工作台）

- DiffSinger 工作台新增「**谱面编辑**」，用通用钢琴卷帘替换原先的表格（保留「列表编辑」兜底，可随时切回，
  选择被记忆）。
- 卷帘能力：键盘列 / 拍线 / 音符块、选择与画笔工具、吸附（1/4~1/32）、Ctrl+滚轮缩放、行高切换、
  点选 / Shift 多选 / 拖动移动 / 左右缘改长与改起点 / 空白框选 / 右键菜单 / 方向键微调 / Ctrl+Z、Y、A。
- **音素条带**：底部独立条带绘制「辅音 → 元音」切分、音素起点线，标签**防重叠交错**，选中音符高亮。
- **音高车道**：底部音高车道（±200 音分），支持 **移动 / 手绘 / 直线 / 正弦 / 平滑 / 清空** 六种工具；
  直线与正弦为 A→B 拖拽、带预览虚线。曲线随工程持久化，并纳入撤销/重做。

### 音高曲线真正「听得见」

- 谱面里画的音高曲线现在**参与渲染**：曲线作为**偏移**叠加在「音符基线音高 → 颤音 → 自由曲线」最后一步，
  用户只在画过的区段附加偏移，区间外不影响发声。
- 选区渲染时曲线与音符时间轴精确对齐（含平移补偿）。
- 引擎新增 **mel 规格健全性校验**（`num_mel_bins` / `mel_base` / `mel_scale`），异常时给出明确中文提示，
  避免出噪音或崩溃。

### 曲谱音素视图（UTAU 工作台）

- 曲谱新增「**音素视图**」开关：在音符内绘制「辅音 → 元音」的音素切分（分界比例按子音速度估算），
  直观看到发音结构，接近 OpenUTAU 的观感。**默认关闭**，不影响既有观感。
- 已有的音高曲线手绘 / 控制点编辑、参数车道、框选 / 多选 / 撤销重做等能力保持不变。

### AI 声库下载体验

- 顶部全局下载通知条显示声库的**可读名称**（如「神里绫华（原神）」），不再显示内部 id。
- DiffSinger 声库走**独立取消通道**，取消声库下载不会再误伤常规模型下载。

## 修复

- **「更新通道切换不持久」**：在设置里选「测试版通道」后重开设置会变回「正式版」，且**真丢**。
  根因是加载路径调用了带副作用的 setter，而设置 store 带缓存，旧值反向覆盖了用户刚选的值。
  现已改为**纯归一化读取**（无副作用），并在切换时同步写内存缓存。（4.5.0-beta.1 已含此问题，本版修复。）
- **「资源中心」显示可下载声库数量为 0**：DiffSinger 声库不在常规模型清单里，导致「模型管理」页的
  DiffSinger 页签徽标与页面副标题恒显示 0。现已接入共享统计，显示真实可下载数量
  （未加载完成前显示「…」而非误报 0）。

## 构建

- 打包配置补充排除规则（`release-*/**`、`*-unpacked/**`）：自定义输出目录（本地测试常用的 `release-test/`）
  此前只被排除默认的 `release/`，会被当作源码打进 `app.asar`，导致包体从 ~64MB 膨胀到 2GB+。

## 升级说明

- 应用内更新：设置 → 更新 → 打开「测试版通道」→ 检查更新
- 全新安装：运行 `FuFumidi Setup 5.0.0-beta.1.exe`
- 本版不涉及安装 / 卸载与数据目录结构，升级不会动你的曲库、模型、声库与设置。
