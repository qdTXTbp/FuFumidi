# FuFumidi v5.0.0-beta.6

**内测版**。这一轮把 beta.5 上线后暴露的几处问题修掉 —— 它们有个共同点：**只在界面路径上才会踩到**，
命令行手测时全都没暴露（我自己的验收方式漏了这一层，已改：界面改动一律用界面跑一遍）。

> 测试版（prerelease）：仅「设置 → 更新 → 测试版通道」开启的用户可收到。

## 修好的问题

- **资源中心：模型全没了。** 新增的 GPT-SoVITS 外部门户条目没有本地落点，
  `path.join(dir, undefined)` 在 try 之外抛错，整个 `model:list` 被炸成空数组 ——
  界面表现就是六个分类的计数全变 0。现在目录扫描跳过这类条目（它们单独 push），
  单个条目出错也不会再清空整份列表。实测恢复 **102 条**（转录 7 / 音色 16 / 分离 29 / 修复 50）。
- **翻唱：音色下拉框空白、点不动。** 选中项与当前分栏不一致：重启后 localStorage 记住的分栏是
  「GPT-SoVITS 音色」，而选中项还是上次 DiffSinger 的声库名，当前列表里找不到 → 下拉框为空、
  「开始翻唱」恒灰。现在改成 watch 兜底：选中的 id 不在当前列表里就自动落到第一项，三种情况都能自愈。
- **翻唱：点「开始翻唱」直接报 argparse 错。** 主进程拼命令时漏了子命令 `all`，
  音频路径被当成子命令名（`invalid choice: …flac`）。
- **翻唱 · GPT-SoVITS：界面发起时 numpy C 扩展加载失败。** 起子进程时把整份环境传下去，
  其中 `PYTHONPATH` 指向 cp311 的 GPU 增强包，被 conda 环境继承后 `Importing the numpy C-extensions failed`；
  现在只保留编码类 `PYTHON*` 变量。
- **翻唱 · GPT-SoVITS：一句唱不了拖垮整首。** 歌词里混入韩文/假名/全角标点会让音素序列变成空，
  模型在 `torch.cat()` 上抛 `expected a non-empty list of Tensors` —— 71 句的歌跑到第 28 句整首失败。
  现在合成前按语言清洗文本，失败按「清洗 → 不切句 → 用「啦」→ **跳过这一句**」逐级回退，整首继续跑完。

## 这一版包含的翻唱工作流（beta.5 起）

- 导航「翻唱」：选歌 → 选音色 → 输出与选项 → 开始。两条音色通道（DiffSinger 声库 / GPT-SoVITS 音色）；
  人声分离复用「音频处理」面板同一套模型，分离结果可直接带进翻唱页。
- GPT-SoVITS 音色走「逐句拿原唱那一句当参考重合成」：参考音自动卡 3.3~9.5 秒、先降噪、
  整段时长拉伸 + 逐句电平配平；每句记旋律/音色客观量。
- 资源中心「GPT-SoVITS 音色」16 条：6 条一键下载（社区微调音色，含参考音）+ 10 条外部门户
  （论坛 / 网盘 / Spaces，标「外部来源」并提供「打开来源」，不假装能一键下载）。
- 断点续跑：分离 / 扒谱 / 分段合成 / 逐句合成都写签名，中途断了再跑只补没做完的。
