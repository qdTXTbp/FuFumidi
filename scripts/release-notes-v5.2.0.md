# FuFumidi 5.2.0

## 界面设计语言重构

- **字号 32 档 → 6 档**、**圆角 31 档 → 4 档**、间距统一到 **4/8 网格**（720 / 374 / 777 处声明）。
- **颜色只剩一个来源**：深浅两档的语义色、抬升、元素数据色全部由主题层按模式发布；组件里的 288 处硬编码色值清零。
- 内置三款字体（合计 812 KB，子集化，离线可用）；表单控件字号继承。
- 新增**控件契约层**（9 类控件的形状与状态），同类控件跨页面一致。
- **命中区全部达标**：五页可点元素小于 28px 的 7/8/11/12/17 → **0**。
- **对比度全部达标**：深/浅两档各 375+ 文本节点 0 个不达标。
- 新增守门脚本 `npm run audit:ui-tokens`（棘轮基线：颜色/字号/圆角/间距四项均为 0）。

## 可视化

- **沉浸模式增强**：真全屏铺满、外壳全隐、控件与进度条自动淡出、**光标一起隐藏**、**Esc 退出**；修掉全屏切换后画布不重算导致的底部留边。

## GPU 加速

- **DirectML 增强包下线**；一键安装只覆盖 NVIDIA → CUDA，AMD/Intel 会明确说明没有可一键安装的包。
- 预打包增强包**不再按 Python 版本拦截下载**：版本不匹配只作提示，按钮始终可点。

## 性能与体积

- 首屏空闲预取重视图分包：首次切到「调教」**2586ms → 6ms**，「视图」598ms → 16ms。
- 打包运行时裁掉第三方 tests 与 C++ 头文件（约 207 MB 未压缩）。

## 其它

- 引擎运行时统一到 **Python 3.12**；移除 3.11 回滚副本。
- 仓库清理：旧安装包、增强包 staging 等 20.9 GB 开发期产物出库。
