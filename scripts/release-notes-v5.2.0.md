# FuFumidi 5.2.0

> 本轮两大块：**变谱（识谱）第二轮大改**（切带 / 拍号推断 / 跨页对齐 / 影像预处理 / 超分 / 逐页重试）与**界面设计语言重构**；
> 另有转录与播放的一批实测修正、可视化底层重做与沉浸模式、体积与清理。

## 变谱（识谱）

- 变谱（识谱）：**拍号推断 + 统一小节网格** —— Audiveris 不导出拍号，以前按「每小节认出来的内容」定长，1217 个小节里只有 43% 是 1440 tick。现在取众数推拍号（实测 6/8，是第二名 3.2 倍）再按「小节号 × 小节长 + 小节内偏移」重排：跨声部同刻发音率 0.357 → **0.735**，音符落在八分网格上 84.9% → **92.7%**
- 变谱：**按系统切带**（失败页兜底）—— 判据是相邻谱表空白带里有没有贯穿竖线，6/6 页与 Audiveris 自己的 GRID 输出逐项吻合；只在乐器组交界切、不劈开大谱表。实测第 2 页（29 行谱表）整页 ×2.11 爆内存、退档被判「Sheet ignored」，现在切成 5 带按 ×3.0 重跑**救回**：6/6 页 1713 音符 187 秒（改前 6/6 但第 2 页靠侥幸、1693 音符、228 秒）
- 变谱：**跨页声部对齐** —— 声部身份改成「(乐器, 声部编号)」。Audiveris 按**系统**出 part，一页 3 个系统就把声部表重复 3 遍，按页内序号对齐会把轨数顶到 43
- 变谱：**乐器名归一 + 移调校正** —— Horn in F −7 / Clarinet·Trumpet in Bb −2 / Glockenspiel +12 / Double Bass −12，轨名带编号（Horn in F 1,2 / Violin I / Violin II）；修掉两处 OCR 误伤（把 Cor anglais/Cornet 读成圆号、把 Flute 1,2 的 e 当调号）
- 变谱：**影像预处理层**（去倾斜 + Sauvola 二值化 + 去噪点）—— 歪的 / 带阴影的 / 拍照的扫描件，两个引擎此前都是**整页失败**。实测同一张旋转 3° + 阴影 + 噪点的真页：关掉预处理时内置经典引擎 0 谱表、Audiveris 判「Sheet ignored」；开启后内置经典 **315 音符**、Audiveris **370 音符**。干净印刷谱逐像素等同旧路径（0.4 秒/页代价）
- 变谱：**超分辨率预处理**（低清扫描件先神经放大）—— 组件用户自装（39.5 MB，MIT，走 Vulkan）。质量对照（参照同一页全分辨率结果，(音高,起拍) F1）：0.25× 钢琴页 **0.081 → 0.883**（少掉的正是插值糊出的假符头）；0.40× 总谱页 **0 → 253 音符**；你自己的清晰总谱页输出 MIDI **逐字节相同**。门槛是量出来的：只在谱表量不出来或行距 < 5px 时动手
- 变谱：**homr（AI 识谱）第二引擎** —— 引擎后端 + 资源中心自行安装（独立 venv，它要 numpy≥2.4 而应用运行时是 1.26）+ 三个 ONNX 权重走镜像下载；没装时如实标「未安装」，不假装可用
- 变谱：**「一键重试该页」** —— 整批跑完把每页结果缓存下来，失败/被跳过的页在结果区显示成可点胶囊，点了用**当前界面参数**只重跑那一页（其余页从缓存读回走同一条合并流水线）。判据抽成纯函数 + 8 项单测
- 变谱：**逐页体检** —— 每页报小节数 / 声部数 / 音符数，并标出问题（空页、各声部小节数不一致、非正时值、超长音、同刻同音重复），结果面板每页一个胶囊、有问题的琥珀色 + 悬停看原因
- 变谱：**速度记号找到新来源** —— 读 Audiveris 的 .omr 里的 metronome 与其后的 word；读准（20~320）就用，读不准如实标 metronome-unreadable 并提示手填。实测这份总谱真值 60 被 OCR 读成 12 → **不采用，绝不猜**
- 变谱：**空态与组件提示重做** —— 空态改成三张可点的谱面类型预设卡（单乐器钢琴谱 / 管弦乐总谱 / 扫描件）+ 三步提示；右栏新增「识谱组件」卡，四行状态（Audiveris / homr / 超分辨率 / OCR 语言包）各带「已安装」或待装体积，卡头一个徽标显示「齐备」或「缺 N 项」；识别参数新增「影像预处理（关 / 自动 / 强制）」
- 变谱：OCR 语言包接线（完整版 tessdata；fast 版无效），组件入口与方法整理到变谱页本身

## 转录与播放

- 转录：**静音分段转录** + 长音符收尾第四版 —— 头部无支撑的幻觉音整颗删掉（星铁 LIVE 26:20 实测）；僵尸音符改按**音调突出度/音频证据**收尾，不再靠时长截断
- 转录：**取消转录真的会停**了、长音符护栏不再被预设关掉；去掉「超长音符上限」开关，默认不截断
- 播放：**跳过空白片段**（修掉开头跳空白不生效）、**方向键步长可配**、**长按倍数播放**（修掉长按快进松手回撤）；三个都是量纲/顺序 bug

## 可视化

- 可视化：**底层重做** —— 图元层 + 状态层 + Canvas2D/WebGL2 双光栅器（全帧平均差 0.41%）+ 着色器后处理（三层倍频带泛光 / 调色 / tanh 肩部）；玻璃音符改用真实透射 + 菲涅尔边缘环，音符与光效一起吃键盘透视，音域外音符（鼓组）不再消失
- 可视化：**沉浸模式** —— 真全屏铺满（含原生标题栏）、顶栏与分组标签全隐、控件与进度条 3 秒无操作淡出、**光标一起隐藏**、Esc 退出；并修掉全屏切换后画布不重算导致底部留边
- 可视化：**动态壁纸背景** —— 音符瀑布的背景新增「动态壁纸」档，可直接用壁纸库里的视频壁纸（缩略图选择 / 下载 / 导入本地视频都沿用壁纸库那一套），模糊与暗化照旧可叠；与应用整窗背景各自独立。视频逐帧变，因此绕开背景位图缓存（缓存键里没有时间，走缓存会永远停在第一帧），模糊在受限尺寸帧上做（4K 全分辨率一次 blur 实测 80~150ms → 现在 ≤1280 宽）
- 可视化：**光效遮挡关系修正** —— 击键光柱/光带/键面辉光原先画在琴键**之前**，下半截被键面切出一条横边；现单独一层画在键盘之后；光柱横向柔化从 3 层离散改为 4 层平缓，去掉阶梯感

## 界面设计语言

- 界面：**设计语言重构** —— 字号 32 档 → **6 档**、圆角 31 档 → **4 档**、间距统一 4/8 网格；颜色只剩**一个来源**（288 处硬编码清零）；内置三款字体（812 KB 子集化，离线可用）；新增控件契约层（9 类控件的形状与状态）
- 界面：**命中区与对比度全部达标** —— 五页可点元素小于 28px 的从 7/8/11/12/17 个降到 **0**；深浅两档各 375+ 文本节点对比度 0 个不达标

## GPU 加速

- GPU：**DirectML 增强包下线**（不再提供下载与安装）；一键安装只覆盖 NVIDIA → CUDA，AMD/Intel 明确告知没有可一键安装的包
- GPU：预打包增强包**不再按 Python 版本拦截下载** —— 版本不匹配只给提示，按钮始终可点；逐模型 GPU 加速状态收进体检报告，修掉翻唱渲染的静默 CPU 降级；修掉 torchaudio 未钉版导致的 WinError 127

## 性能与体积

- 性能：首屏空闲**预取重视图**分包 —— 实测首次切到「调教」从 2586ms 降到 **6ms**、「视图」598ms 降到 16ms
- 体积与清理：打包运行时裁掉第三方 tests 与 C++ 头文件；仓库里 20.9 GB 开发期产物出库；安装器改用最高压缩档

## 其它

- 音频模型配置：28 个 msst 配置 yaml 从仓库移除，改为**下载时获取**（共享缓存 + 上游名模糊匹配 + 同族候选 + 现场生成自愈），分离前自愈一次；实测 42 个配置全部到位、0 失败
- 服务端：修掉反馈函数的依赖打包问题（裸导入致 502）+ 限流降级自报，两轮端到端实测通过；构建排除 netlify/deno 目录（17.4MB node_modules 不再进安装包）
- 品牌：新图标（头像特写 + 透明底）、首页工作区立绘、安装器/卸载器/更新器品牌图与任务栏图标同步
