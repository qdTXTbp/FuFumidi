# FuFumidi 6.2.7

本版合并 GitHub 6.2.6 的模型管理更新，并保留本地按 6.2.1 恢复的乐器组行为。

## 合并 6.2.6

- 乐器组标签模型纳入资源中心统一管理：下载副本优先，随包兜底。
- hFT-Transformer 改从自有双端 models 仓库下载。

## 乐器组

- 只有：不限定 / 限定乐器组 / 自动探测（分段）。
- 自动探测按段进行：每段独立用音频标签模型探测，并按段套用允许乐器组。
- 默认探测段长 60 秒，范围 20–120 秒。
- 移除「音色稳定」选项、复选框与 timbre_stabilize 后处理。

## 音频标签模型

- AudioSet zipformer-small
- CED-Small（约 23 MB）
- 固定 10 秒模型窗口；60 秒段长均匀抽取多个窗口。

## 默认

- 自动 BPM 开启。
