# FuFumidi v4.0.1

本次更新集中在**云同步的可靠性与速度**，并补齐了音色库。

## ☁️ 云同步改进

- **增量上传**：只上传有改动的曲目，不再每次把整个曲库重传一遍。连续同步且本机无改动时，会直接提示「本机曲目均无改动，无需上传」。
- **进度与用时可见**：上传 / 下载过程显示阶段说明、进度条与已用时，长时间同步不再像卡住（手机端 FuMiVoice 同步也已同步支持）。

## 🛠 修复

- **转录后的曲目无法同步**：转录并加入播放列表的 MIDI 会提示「本机找不到 MIDI 内容，已跳过备份」。原因是文件二进制读取返回的字节类型没有被归一化，被误判成「没有内容」。现已统一归一化，此类曲目（含此前已导入的老记录）无需重新导入即可正常备份。
- **曲库备份迁移可能丢字节**：本地库与备份做迁移时，若记录里的字节是另一种类型，会被写成空数组，迁移后曲目变成空壳。现在迁移改为**取两边的并集**，并自动补齐缺失的 MIDI 字节。
- **同一个音色库在电脑端与手机端听感不一致**：电脑端用的 FluidSynth 默认开启混响与合唱，而手机端 FuMiVoice 用的 BASSMIDI 两项默认关闭，所以同一份音色在两端听感不同（电脑端更"湿"、带空间感，手机端干净贴耳，单声道音色库如 FluidR3 Mono 尤其明显）。现已在电脑端关闭这两项，两端听到的是同一个声音，导出的音频也与之一致。
- **同一首 MIDI 在电脑端与手机端的乐器对不上**：电脑端此前把「音轨序号」当 MIDI 通道，并且整条轨只用一个音色；轨号超过 16 的多轨文件里，第 16 轨之后的所有轨道会挤到同一个通道，鼓轨还会把这条通道整条变成鼓组（于是合唱、贝斯等声部一起变成鼓）。同时，轨道中途换音色、音色事件写在别的轨里、用 CC0 选音色库这几种情况也都取不到正确音色。现在改为**逐音符使用文件里的真实通道**，并按「该通道在该时刻」的音色（program）与音色库（CC0）发声，中途换音色同样生效；音色库里没有指定库号时退回 0 号库，与手机端表现一致。导出的音频使用同一套映射。
- **同一个音色库、同一首曲子，两端演奏细节仍不同**：电脑端此前**完全不播放 MIDI 的通道事件** —— 音量（CC7）、声像（CC10）、表情（CC11）、延音（CC64）以及弯音全部被忽略，于是声部平衡、渐强渐弱、钢琴踏板与弯音都和手机端不一样。现在这些事件与音符放在同一条时间轴上一起下发，缩放/变速时同步换算时间；拖动进度条后也会补发该位置之前已经生效的通道状态，跳转后不会沿用旧的音量/表情。导出的音频同样包含这些事件。

## 🎹 音色库

- 新增 8 款音色（来自手机端 FuMiVoice 音色库）：FluidR3 Mono、FM GM Mini、Giga FM GM、Yamaha Grand、Galaxy EP、SuperSaw、Florestan、Vintage Dreams。
- 音色卡片标注分类（通用音色库 / 单音色强化 / 合成与电子 / 轻量音色库）；对较慢的下载源给出耗时提示。

## 📦 安装与更新

- 4.0.0 及以下用户：应用内「检查更新」增量升级（推荐，只下载改动部分）
- 完整安装包：`FuFumidi-Setup-4.0.1.exe`

> 云同步是可选功能：不登录、不点同步时，应用依然完全离线运行，转录与编辑不上传任何数据。
