# FuFumidi v3.2.6

## 修复
- **导出 WAV / 视频音频「2 倍速且重复两遍」**：WAV 编码器声道平面写入改为标准帧交错，导出与播放完全一致
- **视频导出音画不同步（约 0.3s）**：离屏画布改用手动帧捕获并对齐时间戳，随负载漂移一并消除
- **长视频导出转码时内存暴涨导致黑屏 / 无法保存**：转码数据改为高效二进制通道传输
- **SF2 音色库选择不保留**（重启后回退内置音色）：现随设置持久化并在启动时自动恢复
- **导出音频音色与播放不一致**：导出改用当前 SF2 音色离线渲染，所见即所得
- **完整性检查 core-corrupt 误报**（v3.1.18 修复在版本合并中丢失，本次恢复）
- **播放时乐谱跟随不生效 / 从其他页面返回乐谱挤在左侧**
- **高负载下动态壁纸停摆**：新增心跳自愈
- **音色切换失败报错**：Verovio 乐谱引擎与合成器的全局模块冲突隔离

## 新增 / 改进
- **转写自动检测 BPM**：通用识别 / 钢琴等引擎转录出的 MIDI 按源音频自动测速，播放与导出速度和原曲一致（转写页可开关）
- 主题库重排：深色 / 浅色两大分类，每主题双版本即点即换，迷你窗口预览所见即所得
- 播放中切页 / 乐谱重绘不再卡顿掉音（SF2 走音频线程音序器，预排窗口扩大）
- 启动性能优化：js-synth（libfluidsynth ~2.4MB）改为按需懒加载，首帧更快

## 更新方式
- 3.2.x / 3.1.x 用户：应用内自动更新（增量更新器差分下载），或下载 `FuFumidi.Install.exe` 离线包覆盖安装
- 新用户：下载 `FuFumidi-Setup-3.2.6.exe` 完整安装
