# FuFumidi v3.1.11

## 新功能
- **GPU 增强包安装走国内加速**：CUDA（cu128）pip 源链阿里云 pytorch-wheels → 上海交大 → 官方自动回退；DirectML 走阿里云/清华 PyPI；预打包增强包下载补充 gh.jasonzeng.dev 加速（与 MuScriptor 分卷同源）
- **GPU 安装常驻通知条**：任意页面可见安装进度与当前步骤，完成后展示成功/失败结果；点击跳转「设置 → GPU」，可手动关闭

## 更新方式
- 3.1.x 用户：应用内自动更新（或下载 `FuFumidi.Install.exe` 离线包覆盖安装）
- 新用户：下载 `FuFumidi-Setup-3.1.11.exe` 完整安装
