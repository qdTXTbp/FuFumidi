# FuFumidi 6.2.5

发布于 2026-10-24。修复升级后「模型与音色全部消失」的问题。**没有任何文件被删除** —— 数据一直在原处，只是应用看错了目录。

## 现象

从便携版升级到安装版（或换了安装位置）后，转录模型、音色库、声库都不见了，界面像是被清空。

## 根因

旧版是便携目录，数据在 `E:\Midi\FuFumidi\FuFumidiData\`：

```
E:\Midi\FuFumidi\
E:\Midi\FuFumidi\FuFumidiData\      ← 模型 / 音色 / 声库都在这里
```

新版本装到了 `C:\Program Files\FuFumidi\`，而启动时按这个顺序找数据根：

1. `C:\Program Files\FuFumidi\FuFumidiData` —— Program Files 普通权限不可写
2. 回退到 `C:\Users\...\AppData\Roaming\FuFumidi\FuFumidiData`

第 2 步在首次启动时**新建了一个空目录**。旧目录从头到尾没被找过 —— 因为候选表里根本没有
「上次用过的位置」这一路，而设置里的 `data_root` 一直是空的（旧版本用完便携目录并不会记录它）。
设置文件里的 `active_soundfont` 仍然指向 E 盘，但它没有被用来反推数据根。

## 修复

选数据根的规则改成 **先看谁真有数据，再看谁可写**：

1. `data_root`（用户显式指定）—— 可写就用，哪怕是空目录
2. `data_root_last`（上次实际用过的位置，本版起自动记录）—— **必须有内容**才认领
3. 安装目录旁的 `FuFumidiData` —— 有内容就用（便携版常态）
4. 从设置里残留的绝对路径反推出的历史数据根（音色文件、壁纸、导出目录、曲库 midi…）—— 有内容才认领
5. `%APPDATA%\FuFumidiData` —— 有内容才认领
6. 安装目录旁（全新便携安装，允许现场创建）
7. `%APPDATA%\FuFumidiData`（兜底创建）

两条关键约束：

- **「必须有内容才认领」**：否则会认领上次故障留下的空壳，问题原地复发。
- **「有内容」优先于「可写但空」**：换了安装位置后不会又看到一片空白。

另外每次启动会把实际使用的数据根记进设置（`data_root_last`），
此后换安装位置、重装、便携转安装都能自动找回。设置页的「数据目录」会显示
**已沿用原数据目录（旧版本位置）**，不再让人误以为数据被清空。

## 你需要做什么

装 6.2.5 后直接启动即可，应用会自动认出旧数据目录并继续使用，不需要手动搬运或重新下载。
如果想确认用的是哪个目录：**设置 → 数据目录**，第一行就是当前路径。

## 顺带修复：MuScriptor「每隔一段时间换一种乐器」

同一个反馈还提到「转录质量大不如前，而且过一段固定时间就换一种乐器，5.0.0 没有」。
查证结论：**不是模型退化，是一项已经过 A/B 固化过的默认被删掉了。**

MuScriptor 逐 5 秒块判定乐器。2026-10-18 做过 A/B 并据此固化为默认：
转录前锁定主乐器组（`probe`）+ 语后把短命孤立的乐器轨并入邻近主导轨（`timbre_stabilize`），
实测 **音色切换 5 → 0、F1 0.4914 → 0.7692**、峰值显存不变。
后来一次「精简高级参数面板」把这两个开关连同界面一起删了，默认悄悄退回「不锁定乐器组」，
于是每 5 秒块都可能换一次音色、F1 也掉回 0.49 —— 这正是你听到的「固定时间换乐器」和
「质量大不如前」。

本版恢复这两项为 MuScriptor 默认，并在转录页把它们做成可见开关：
· 「自动锁定乐器组（音色稳定）」档位（默认选中）
· 「音色稳定」复选框（默认勾选）

想关掉任何一项都可以在界面上直接改。

## 顺带说明

- 若旧目录在移动硬盘/网盘上且当前没插，应用会跳过它（不会认死路径），插上后下次启动自动接回。
- 若你已经在新的空目录里重新下载过少量模型，应用仍会优先回到旧的大目录；那些重下的文件留在原处不删。
