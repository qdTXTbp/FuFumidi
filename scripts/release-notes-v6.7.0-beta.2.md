# FuFumidi 6.7.0-beta.2（测试版）

> 这是 **beta 通道**版本：只有设置里把更新通道切到「测试版」的用户会收到，
> 正式版通道仍停留在 6.6.3，不会提示更新。

本版补齐三件被反复提到的能力：音频导出格式、轨道颜色一致性、AMD 显卡自检。
不带界面大改，风险面比 beta.1（Electron 38 + 全站动效）小得多。

## 导出 · 新增 MP3 / FLAC / OGG

以前只有 WAV 三档，README 里写的 MP3/OGG 其实没实现。现在导出格式变成 6 项：

- **WAV 16 / 24 / 32-bit float**（不变）
- **FLAC 无损**、**MP3 320 kbps**、**OGG Vorbis Q6**（新增）

实现方式：渲染进程仍只产 **24-bit WAV 母版**（避免有损格式从 16-bit 二次损失），
压缩格式由主进程用安装包内已有的 ffmpeg 转码，最后走同一套原子落盘 + sidecar 校验清单。
不联网、不新增依赖、不改变 WAV 导出的行为。

## 编辑 · 轨道颜色全界面一致（issue #39）

同一个乐器以前在不同页面可能是两种颜色：卷帘里是红、混音台里是蓝（Voice 则是土黄 vs 紫）。
根因是仓库里有两套调色板、顺序不同：一套 8 色主题色板、一套 10 色固定序列。

现在统一走 `palette.trackColor()`：卷帘 / 混音台 / 分析页 / 乐谱页 / 迷你卷帘取同一个值，
并且**跟随深浅主题**——切主题时轨色会一起变（以前不会）。超过 8 轨按 8 回绕。

## 加速 · AMD ROCm 自检不再只看「驱动认卡」

以前安装完只检查 `torch.version.hip` 非空，RX 6000/5000 这类不在当前 ROCm 包里的卡
也会显示「已启用」，直到第一次转录才报 `no kernel image is available`。

现在安装后会：

1. 读真实设备名与显卡架构（gfx）；
2. **真跑一次 256×256 矩阵乘并与 CPU 对拍**；
3. 失败时直接说明「你的 gfx 不在当前包支持的 7 个架构里」，并建议先用 CPU。

> 注意：这一版**没有**新增对 RX 6000/5000 的支持——它们的运行时需要 AMD TheRock 的
> Windows 架构包，尚未提供。本版只是让不支持的卡在安装时就说清楚，而不是中途崩。

## 测试版请重点留意

1. **导出**：选 MP3/FLAC/OGG 各导一次，确认文件能播放、扩展名与内容一致；
   长曲目转码会比 WAV 慢一些。
2. **轨色**：在卷帘、混音台、分析页、乐谱页对照同一条轨，颜色应一致；切换深浅主题再看一次。
3. **ROCm**：有 RX 7000/9000 的用户可重装一次加速包，看自检是否通过；
   没有 A 卡的用户不受影响。
4. **回归**：本版未改播放/转录路径，但 Electron 运行时仍是 38，若遇到 beta.1 就有的问题请一并反馈。

升级路径：设置 → 关于/更新 → 通道选「测试版」→ 检查更新。
正式版用户无需操作，也不会收到本版提示。
