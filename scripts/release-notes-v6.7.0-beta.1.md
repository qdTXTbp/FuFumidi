# FuFumidi 6.7.0-beta.1（测试版）

> 这是 **beta 通道**版本：只有设置里把更新通道切到「测试版」的用户会收到，
> 正式版通道仍停留在 6.6.3，不会提示更新。

本版做两件视觉层的地基改造，并把运行时升到 Electron 38。

## 动效 · 全站改用阻尼弹簧参数

以前每个面板、按钮、弹层各自写 `duration + cubic-bezier`，回弹感不统一，改一处要翻几十个文件。

- 现在由**一套阻尼谐振子参数**推导：`stiffness`（刚度）、`damping`（阻尼）、`mass`（质量）。
- 阶跃响应直接采样成 CSS `linear()` 缓动，浏览器端跑的是真实阻尼曲线，不是贝塞尔近似。
- 派生三档速度（快 / 标准 / 慢），并回填旧的 `--motion-*`、`--ease-*` token；
  现有 200+ 处过渡无需逐条改写，改一次参数全站同步。
- 参数入口在 `frontend/src/core/motion.js`（`DEFAULT_SPRING`），也支持写入
  `localStorage.fufumidi_motion` 覆盖，方便调试。
- `prefers-reduced-motion` 仍然强制关闭动画。

## 圆角 · 全部改为连续曲率

- 所有 DOM 圆角统一使用原生 `corner-shape: squircle`：切线连续，不再有圆弧与直边的硬度突变。
- 头像、状态点、开关滑块、播放键等需要正圆的元素显式保留 `round`。
- Canvas 侧（钢琴卷帘音符块、编排片段、转换页波形卡片、可视化图元）换成四阶超椭圆路径
  （`core/canvas_shape.js`），与 DOM 观感一致。
- 不支持 `corner-shape` 的宿主会自动退回普通圆弧，不会出现无圆角。

## 运行时 · Electron 37 → 38（Chromium 140）

- 原生连续曲率需要 Chromium 139+，因此随本版升级运行时。
- 系统要求不变：Windows 10 1809+ / x64。
- 覆盖安装即可，设置、曲库、工程文件路径不变；更新器、签名清单与安装包格式不变。

## 测试版请重点留意

1. **性能**：圆角与动效都是原生绘制，理论上无额外合成层；若某些页面出现掉帧请附上页面名。
2. **壁纸 / 可视化**：Chromium 138 → 140 的 WebGL 回归是本次最大风险点，请试一下动态壁纸与可视化页。
3. **媒体**：音频播放、视频封面、波形与频谱是否正常。
4. **正圆元素**：头像、状态点、开关滑块在 squircle 下应保持正圆。

升级路径：设置 → 关于/更新 → 通道选「测试版」→ 检查更新。
正式版用户无需操作，也不会收到本版提示。
