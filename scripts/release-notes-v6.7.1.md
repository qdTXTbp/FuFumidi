# FuFumidi 6.7.1（正式版 · 修「卷帘」）

> 本版只动「卷帘」页签，其余部分与 6.7.0 完全相同。
> 已装 6.7.0 的用户走正常更新（增量包约 164 MB），不需要下载完整安装包。

## 修复 · 卷帘对真实曲目一片空白

6.7.0 里点进「卷帘」会看到「还没有可画成卷帘的音符」，即使曲目明明有音符。原因是读了两处错：

1. **读错了对象**：音符住在 `currentSong.song.tracks[].notes`，不是 `currentSong.tracks`
   （后者是曲库条目，没有音符）；
2. **读错了时间域**：`notes[].start/end` 是 **tick**，不是秒。现在统一走
   `song.baseSec(tick)` 换算，变速曲目也对得上。

## 新增 · 多轨 MIDI 可以选择音轨

很多 MIDI 把钢琴、弦乐、鼓、人声分在不同轨上，全部叠在一张卷帘里既挤又难读。

- 参数条下方新增一排音轨按钮：**轨道色点 + 轨名 + 音符数**；
- 可多选 / 取消，默认勾选**所有有音符的轨**；
- 空轨置灰、不可选（但列出来，方便你确认它确实没有音符）；
- 一轨都不选时给明确提示，而不是误当成「全选」。

## 观感 · 高亮更明显

- 未播放的音符：淡化到 **30% 不透明度**，退成底图；
- 正在响的音符：实色 + 一圈辉光，一眼能看出这一拍在响哪些音。

## 升级建议

1. 打开任意多轨 MIDI → 「音乐 → 卷帘」：应立刻看到音符，下方能勾选音轨；
2. 取消勾选几条轨，卷帘应立即变稀；
3. 点「开始」，播放头走过时对应音符应变亮。
