# FuFumidi 6.1.1

## 转录队列：运行中可新建队列 · 每个队列指定产物歌单

- **转录进行中也能「新建队列」**：新队列只加入队列列表，不打断当前批次；当前批次结束后切换即可。
  （运行中仍禁止切换/删除队列 —— 半路换模型与参数会让同一批结果无法解释。）
- 每个队列新增「**产物歌单**」下拉：跟随当前歌单 / 仅加入全部曲目 / 指定歌单。
  一批转录开始时快照目标，完成后按该目标加入歌单；运行中下拉禁用，避免同一批落在两个歌单。

## 识别片段长度（所有转录模型）

- 高级参数新增「**识别片段长度**」滑条：0 = 各模型默认；>0 时统一按秒控制一次喂给模型的音频长度（引擎夹紧到 2–120s）。
- 各模型映射：
  - **Basic Pitch**：按片段切片逐段识别再合并 MIDI；
  - **MuScriptor**：改内部块长（默认 5s），跨块延音缝合按新块长；
  - **piano-transcription**：`segment_samples = 秒 × 16000`；
  - **Transkun**：`--segmentSize / --segmentHopSize`；
  - **Aria-AMT**：启动包装注入 `LEN_MS / CHUNK_LEN_MS`。
- 该参数随参数预设与队列设置一起保存；不设置时与旧版行为完全一致。
