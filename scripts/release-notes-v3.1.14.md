# FuFumidi v3.1.14

## 修复
- **一键修复真正生效**：完整性检查发现核心文件损坏（core-corrupt / core-missing，如升级中断导致 app.asar 被截断）时，点击「一键修复」将**自动下载最新安装包并静默重装**恢复，无需手动操作；下载失败时明确提示并可跳转 GitHub Releases 手动下载
- 核心文件损坏检查现纳入一键修复范围（此前无法自动修复被静默跳过，导致点击无反应）

## 更新方式
- 3.1.x 用户：应用内自动更新（或下载 `FuFumidi.Install.exe` 离线包覆盖安装）
- 新用户：下载 `FuFumidi-Setup-3.1.14.exe` 完整安装
