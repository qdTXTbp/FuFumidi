# FuFumidi v4.0.2

本次恢复**曲目列表批量管理**，并修复转录「节拍网格检测」开关无效的问题。

## 🗂 新增：曲目列表批量管理

- 侧边栏曲目列表上方新增「批量管理」入口：进入后每行出现勾选框，行内 ♥ / ＋ / 移除 图标与拖拽把手自动隐藏，单击或双击都是勾选。
- **多选 / 全选**：「全选」作用于**当前可见**的曲目，搜索与「整理方式」（艺术家 / 专辑 / 流派 / 文件夹）同样生效，再点一次即取消全选。
- **批量操作**：
  - `移到歌单…` —— 选中多首一次性移到目标歌单（目标不是当前歌单时从当前歌单移除，避免重复留存）
  - `收藏` —— 选中的都已收藏时自动变为 `取消收藏`
  - `移除` —— 语义与单行按钮一致：**全部曲目**下是「从资料库删除」（二次确认，并从所有歌单移除），**歌单**下是「从歌单移除」，**收藏**下是「取消收藏」
- 切换歌单 / 修改搜索 / 更换整理方式后，选中项会自动收敛到当前可见范围，`已选 N` 始终与实际可操作对象一致。

## 🛠 修复

- **音色库播放时混音台完全失效**：音色库（SF2）的输出只有一路混合节点（`sf2Node → master`），而混音台只调 Web Audio 的「每轨增益」，音色库的输出根本不经过那条路径 —— 所以加载音色库后，音量推子、静音、独奏、声像全部没有反应（内置合成器模式下才有效）。现在音色库模式改用 MIDI **通道音量(CC7) / 声像(CC10)** 混音：
  - 音量、静音、独奏**立即生效**，包括正在发声的音符；且**不改变音色**（不像用力度缩放那样会影响 SoundFont 的力度分层）
  - 用户推子与文件自身的 CC7 自动化是「**推子优先、自动化打底**」的叠加关系：通道实际音量 = 文件 CC7（文件没写过则按最大值）× 推子 × 静音/独奏
  - 粒度为 **MIDI 通道**，与手机端 BASSMIDI 播放同一文件时的模型一致；同一通道上的多条轨物理上分不开，会一起变化（混音台每行已标出 `Ch` 通道号，便于对照）
- **转录「节拍网格检测（Beat This!）」勾选后不生效**：界面开关虽然传给了主进程，但引擎 worker 在把请求转换成参数时**漏掉了这个字段**，`params` 里恒为关闭，因此日志固定输出「已关闭节拍网格检测」，权重下载了也不会被加载。现已补齐该字段（并补充命令行 `--beat-grid` 开关），勾选后会加载本地权重做时值对齐；未下载或加载失败仍按原逻辑自动跳过，不影响转录。

## 📦 安装与更新

- 4.0.1 及以下用户：应用内「检查更新」增量升级（推荐，只下载改动部分）
- 完整安装包：`FuFumidi-Setup-4.0.2.exe`

> 云同步是可选功能：不登录、不点同步时，应用依然完全离线运行，转录与编辑不上传任何数据。
