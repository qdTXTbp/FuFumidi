# FuFumidi 6.2.0

## 界面

- 全界面品牌重构：深海蓝、天蓝与金饰；12 套主题、动态 / 静态壁纸、玻璃材质。
- 移除所有页面标题“贴片”、黑色底条与壁纸暗角遮罩。
- 曲目标签按内容宽度均分顶栏，单标签不再拉满。
- 输入控件统一 UI 字体，修复“未命名轨”字体回退。

## 外观与壁纸

- 外观功能全部迁入专门外观抽屉：主题、强调色、壁纸、字号、密度、缩放、语言、减弱动态。
- 统一壁纸库：动态仓库、在线静态搜索（Wallhaven）、外链文件夹（只登记路径）、图片/视频直链下载；静态与动态同一网格切换。

## 导航

- 「曲库」更名「音乐」：演奏 / 可视化 / 乐谱。
- 工作台：编辑 / 歌词 / 分析 / 编排。
- 旧深链自动重定向，标签页状态与导航历史保持兼容。

## 编辑器与编排

- 编辑器紧凑菜单栏、可拖动高级工具浮层、上下文操作条。
- 编排双击片段按 trackId 精准定位对应轨道，并选中片段内音符；空轨道从轨道列表隐藏。

## 新手引导

- 6 章 19 步章节式引导，支持单章学习、完成度记录、继续学习与 F1 重开。

## 验证

- UI 546 / E2E 29 全绿；安装版冒烟通过。
