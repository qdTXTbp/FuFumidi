# FuFumidi 6.0.0

> v6 是底层契约与工作流的一整轮升级：命令/任务/会话/时间轴四套契约落地，
> 编排时间线、分析升级、质量基准、字级咬字对齐、影视帧吸附、更新包签名、
> 存储治理与性能门禁一并进入应用；P2 的插件节点、MIDI 2.0/MPE/时钟协议、
> 跨平台 dev 入口也已完成协议层与构建入口。已知环境依赖项见文末。

## 编辑器 / 编排

- **编排时间线（视图 → 编排）**：clip 视图、拖拽移动（含跨轨）、拖边缩放、按播放头切分、标记/区间、
  **标尺拖拽框区间**、双击片段跳编辑页；编排状态持久化到曲目并在转换页「按编排片段导出」。
- **手势状态机**：点选/拖动/拖边缩放/框选/平移/画笔/橡皮统一判定（3px 阈值，一次手势=一条撤销项）；
  **撤销/重做**走 C1 命令注册表（工具栏 + Mod+Z/Mod+Shift+Z）。
- **选区批量操作**：全选后移调/八度/力度/量化/删除/克隆；全流程 E2E 数据回读验证。
- **曲线引擎**：点运算（简化/量化/平滑/缩放/合并）+ MIDI 弯音（±2 半音，中心精确）+ **编辑器弯音泳道**。
- **跟随播放**：播放时视口按策略滚动（越界才滚），可与手动滚动共存；mini-map 导航与选区循环。
- **影视配乐**：23.976/24/25/29.97/30 fps **帧吸附**（时间域，变速曲目正确）、HH:MM:SS:FF 时间码、视频偏移与播放同步。
- **控件契约 / 任务模板 / 专家模式**：同一语义同一快捷键（冲突/漂移检测）；钢琴改编/乐队编曲/短视频 BGM 模板；
  普通模式隐藏 OMR/翻唱/GPU 高级入口。

## 分析 / OMR / 咬字

- **分析升级**：K-S 转调滑窗 + 转调段、和弦+能量段落聚类、罗马数字、和弦轨**写回 MIDI marker**（可重复执行不累积）。
- **质量基准（P1-3）**：6 个确定性合成样本、note/onset/pedal F1、identity=1.0、**−2% 门禁**进 npm test。
- **OMR 收口**：Audiveris / homr / 内置经典引擎多后端；失败页可解释、**按页重试**、逐页体检；
  新增可选 **SMT 后端适配器**（自备推理命令，未配置时明确报错不静默降级）。
- **咬字与歌词对齐（P1-5）**：逐句字级对齐（能量谷底 + 字数先验，中位边界误差 <30ms）、
  **丢字检测**（retention<95% 写入合成 warnings）、结果落 lines.meta.json。

## 工程 / 系统

- **命令注册表 C1 + 命令面板**：菜单/工具栏/右键/快捷键/面板共用一份命令表。
- **任务中心 C2**：长任务登记在主进程、10Hz 合并进度、可取消；离开页面不丢。
- **自动保存/恢复 C3**：FNV 脏检测、30s 落盘、崩溃恢复横幅。
- **时间轴模型 C4**：tempoMap/变拍号/SMPTE 统一换算，编辑器与乐谱/编排共用。
- **导航历史 / 深链接 / 会话恢复 / 多标签页**：应用内前进后退、7 天会话恢复、曲目标签切换。
- **设置可搜索**：20 个设置项（含别名：字大/显卡/升级…），点结果切页签并滚到锚点。
- **存储治理**：10 类占用分类、安全清理（**曲库永远不清**；资产需显式勾选；日志保留最近 5 份）。
- **许可与溯源**：从代码/VENDOR.md 生成许可清单 + 关于页；WAV 导出写 **BWF bext + LIST INFO**；
  MIDI 导出写版权元事件（0x02）。
- **更新包签名（P1-8）**：安装包 Ed25519 清单签名，更新器下载后**验签失败即删除并拒绝安装**；
  旧版本无清单时跳过并告警（6.0.0 起发版必须带清单）。
- **性能基线（P1-10）**：npm run perf:gate 覆盖启动/视图切换/60k 音符帧时间/堆增长。
- **P2 协议层**：离线插件节点（gain/EQ/compressor/saturator，接导出链）、MIDI 2.0 UMP/MPE/MIDI Clock、
  音频 I/O 后端契约与 RTL 实测报告、跨平台 dev 构建入口。

## 升级与兼容

- 数据根、曲库与设置格式保持兼容；首次启动会显示本更新日志。

- **WASAPI 独占 / ASIO 原生音频 I/O** 未随包：当前为 WebAudio，本机实测 interactive 10ms / playback 20ms
  （RTL 目标 ≤10ms 只有原生后端能稳定达到；报告见 docs/audio-rtl-report.md）。
- **macOS / Linux 仅为 dev 包入口**：未签名未公证、未真机验证；Windows 是正式发布平台。
- **真实 VST3/CLAP 插件宿主**未接入：本轮交付可测的离线插件节点契约与内置等效节点。
- **Authenticode 代码签名**待证书采购（更新包已用 Ed25519 清单验签兜底）。
