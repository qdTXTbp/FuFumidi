# FuFumidi 6.6.3

本版把四件「已经做完但还没串起来」的能力一起交付：
**编排自动化片段**、**参数化 MIDI 工具**、**引擎子进程守护**、**启动闪屏**。

## 编排 · 自动化片段

以前自动化曲线是轨的「子轨」：一条曲线从第 0 拍铺到结尾，不能单独移动、复制或循环。
本版在演唱页的编排时间线上补了 playlist 一级对象 —— **自动化片段（Automation Clip）**。

- 每轨底部新增自动化条带，片段以矩形显示，内部画出迷你折线；开启循环时画出循环边界。
- 选中后可 **拖动**（吸附 1/4 拍）、**左右裁剪**、**复制**、**循环**、**删除**，以及 **淡入 / 淡出**。
- 片段有独立放置区间，内部点坐标相对于片段起点：移动/复制片段不会改动片段之外的原曲线。
- 裁剪左边界时同步平移内部点，片段内听到的内容不漂移；裁剪不会短于最小长度。
- 每个动作单独占一个撤销点；拖动过程中只在手势开始时记一次历史，不会把撤销栈刷爆。
- 淡化不是「拉回 0」，而是朝**基础曲线值**线性混合：音量淡出不会变成静音，音高淡出不会跑到 0 音分。

### 已经接进播放与导出

- 片段覆盖的拍位优先于轨内整条曲线，结果确定（同轨同参数多条片段时后者覆盖前者，不做加法混合）。
- 演唱播放（VOL / PAN）与导出链路统一走同一套采样：
  UTAU 的 DYN / BRE / GEN 曲线、DiffSinger 的 `pitchCurve` 都带上片段与淡化结果。
- 工程文件、撤销快照同步保存片段；旧工程缺这个字段时按空列表读取，不影响打开与播放。

## 编辑 · 参数化 MIDI 工具

编辑页原本 67 个「一键动作」，每个都是独立按钮 + 一段写死逻辑：想「移调 +3，再力度 ×0.8」
要点两次、撤销两次，也没法存成预设。

- 工具面板改为**声明式注册表**：23 个工具分 **音高 / 力度 / 时值 / 节奏 / 生成** 五组。
- 界面由参数表自动生成（滑杆 / 下拉 / 开关），拖动参数即可**实时预览**（从基线重算，不会累积误差）。
- 确认后所有改动只落**一次撤销**；生成类工具（如 Flam、Slice）新增的音符会在取消时整体撤掉。
- 参数组合可存成**预设**，下次一键复用；需要随机性的工具从固定 seed 派生，拖动别的参数时结果不会乱跳。

## 引擎 · 子进程守护

原来引擎崩掉后是「下一次请求自然重启」，没有节奏控制：必现的崩溃会让用户每点一次炸一次，
日志与任务中心被同样的失败刷屏。

- 以引擎输出的 `###READY` 判定就绪（带超时兜底旧引擎目录）。
- 连续崩溃按指数退避重启（600ms → 1.2s → 2.4s …，上限 8s）。
- 60 秒内崩溃 3 次触发熔断，暂停重启 30 秒，并给出明确原因。
- 只负责进程生命周期，**不重放**已经发出的任务 —— 避免转录被跑两遍。

## 启动 · 闪屏

- 主窗口加载完成前先显示深色启动页，避免启动瞬间白屏。
- 加载完成后卡片在渲染层用弹簧参数铺满窗口，再通知主进程显示主界面。
- 不使用透明全屏窗口或逐帧改窗口尺寸，远程桌面与部分显卡上更稳。

## 升级说明

- 覆盖安装即可，设置、曲库、工程文件保持原样。
- 6.6.2 及更早的工程没有自动化片段字段，打开时按空片段处理。
- 本版没有引擎运行时的破坏性变更，GPU 增强包无需重装。
