# FuFumidi v4.3.0

这一版动静比较大：修掉了一批「一直在默默影响体验」的问题（有几个是打开某个开关之后
整个功能其实从未生效），并把可视化做成了可以「沉浸式」看的形态。

## 修复

### 播放与音效

- **打开「启用音效」会让整个应用变成静音**。音效链的入口接上之后没有连到均衡器第一级，
  而开启时又断开了原来的直连——信号进去出不来。均衡器 / 低音增强 / 空间声这三个功能
  因此从未真正生效过。现已接通，并去掉了与之并联的一条重复干路
  （它会让电平翻倍、约 +6dB），单声道音色库在展宽时也不再丢右耳。
- **空间声对右侧声像不起展宽作用、反而把本侧压小**。右耳的展宽分量符号写反，
  对以右声道为主的声像开到最大时，左右都只剩一半（本侧 −6dB），左耳得到的是反相副本；
  以左声道为主的声像则完全正常，因此这是个只影响右侧的不对称缺陷。
  总电平守恒，所以此前只测总电平的验证看不出这个问题。现已左右对称，居中信号完全不受影响。
- **播放速度按钮方向与界面相反**。内部把「速度倍率」当成了「时间倍率」（两者互为倒数），
  按「加速」实际在放慢；播放时间文本在倍速下也会被按倍率放大，导致曲尾淡出失效或误触发。
  现在加速即加速，时间文本与总时长统一到同一条歌曲时间轴上。
- **极密的曲目播放时完全没有声音**。发声节点超预算时的回收策略按「结束时间从早到晚」
  挑牺牲对象，而结束最早的恰好是此刻正在响的那批音——整首歌被逐个掐掉，表现为数字静音
  （音频图、包络、节点全都正常）。现改为优先回收「还没轮到发声」的预排节点。
- **极密曲目（内置合成器发声）仍会丢掉约四成音符**。内置合成器是「预排即建节点」，
  1 秒预排窗口在约 180 音符/秒的段落里就会顶满节点预算，于是持续丢弃还排在窗口里的音。
  现在节点占用接近预算时不再继续往后排（把「丢音」换成「预排窗口变浅」），实测丢音 0 个。
- **接外部音源播放越久越卡**。活跃音符表的清理逻辑只写在内置合成器分支里，
  接外部音源（SF2）时从头到尾不清，一首 5 分钟的密集曲目能累积数万条。
  现在清理对所有发声路径生效。
- **节拍器打开后关不掉**。点击声会在整个预排窗口内一次排完（接外部音源时可达 30 秒），
  而关闭或暂停只翻了标志位，已排好的点击声仍会继续响。现在这些点击声会被一并取消。
- **音频引擎初始化中途失败会留下「必须重启应用才能恢复」的状态**。现在初始化改为
  整体成功才生效，失败时如实报错并清理，后续操作可重新初始化。

### 界面与编辑

- **大曲目下播放页每帧扫到全曲末尾**。钢琴卷帘的「只绘制视口附近音符」上界判断写反，
  裁剪完全失效。6 万音符实测 3.3ms/帧。
- **音符数较多时「逻辑编辑器删除 / 删除短音 / 清除鼓点 / 批量调响度」会卡住**。
  这几处是逐个线性查找再逐个删除（合计 O(N²)）。改为一次性收集、倒序单趟移除。
- **繁體中文下所有「已移动」显示成「已移送」**。转换表里误把「移动」收成了用词替换，
  而它只需要字形转换。

## 新增

- **可视化「沉浸模式」**：顶栏、侧栏、播放栏一并隐去，音符瀑布独占整个窗口，
  底部换成本页的浮层控制条。鼠标静止 3 秒后控件自动淡出，只留画面；
  按 `I` 进入，`Esc` 退出。

## 改进

- **音符瀑布的纵深观感**：音符越靠近击键线越亮、越靠屏顶越淡并略微收窄，
  发光强度随力度变化，跨过击键线时从琴键上迸出粒子；背景随音乐能量脉动
  （视频导出与实时预览使用同一套能量算法）。
- **音符瀑布滚动时的轻微闪烁**已消除。画面此前按 CSS 像素取整，而高分辨率屏的
  设备像素比常是 2.5、滚动速度约 0.93 像素/帧，于是每帧位移在 2 与 3 个设备像素之间跳。
  现在随播放移动的内容按精确坐标绘制，琴键高亮改成约 0.18 秒的余辉淡出。
- **深色主题下琴键不再是一整块亮白色**，配色跟随主题。
- **音符瀑布的缩放**改为缩放「可视音域」宽度，放大后不再把右侧半个键盘裁掉。
- **音符瀑布每帧的绘制开销大幅下降**：按音高预合并一次并复用、每帧二分跳过已划过的段落；
  琴键底色渐变由每个键各建一个改为整屏共用（90 个/帧 → 4 个/帧）。
- 大音符量下的批量增删改、极密曲目的可视化与播放页帧时间都有明显改善
  （6 万音符压力曲目：帧时间 p50 由 70~113ms 降到 24~25ms，绘制耗时 3.6ms → 2.7ms）。

## 升级说明

- 增量更新：设置 → 更新 → 检查更新（走 ghfast 镜像，仅下载改动部分）
- 全新安装：运行 `FuFumidi Setup 4.3.0.exe`
- 本版改动集中在音频与渲染，不涉及安装/卸载与数据目录结构，升级不会动你的曲库与设置。
