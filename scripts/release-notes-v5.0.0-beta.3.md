# FuFumidi v5.0.0-beta.3

**内测版**。这是 5.0.0-beta.2 之后 89 个提交的合集：**调教与编辑的深度补完**、**体积明显变小**、
**多语言不再半途失效**。

> 测试版（prerelease）：仅「设置 → 更新 → 测试版通道」开启的用户可收到。

## 调教（歌声合成）

- **音高曲线画布**：画笔 / 直线 / 橡皮 / 平滑 / 量化，一次拖拽只产生一个撤销点；每条引擎参数都能直接画
  （自动化页签）；颤音改成三滑杆并带包络预览；曲线可锁定、可按引擎过滤复制到其它轨。
- **和声组**：建组 / 改名 / 加成员 / 切组 / 解散；组级静音与独奏、组内统一音量与量化、整组移调，
  都只产生一个撤销点并写进工程文件。
- **跨轨选区与跨轨拖动**：框选 / 加选可以跨越叠置的幽灵音符，整组拖动是一次撤销点。
- **键盘流与音素视图**：Tab / Ctrl+方向键 / 数字键编辑音符属性，详情面板分组；音素时间表
  （边界、时长毫秒、点行选中）与音素波形底图（整音 / 音素秒级试听）。
- **渲染**：乐句级增量渲染 + A/B 对比；多音字候选一键替换；`--vocoder` 覆盖真正生效；多语声库可以唱了。
- **声库制作**：别名表可直接编辑并调用真实引擎试听（写回保持原 oto.ini 的编码与行尾）；新增音域热力图、
  oto 参数一览表、Shift-JIS / UTF-8 编码切换；歌词「切开长音符」按时间轴对齐。
- **修复**：DS 渲染进度条、声库下载进度不再随页签消失、DS 渲染的 BPM 与句首留白、导出 WAV 失效、
  sampleNote 默认值、OpenUtau 缓存串味、卷帘与调教页各走一步撤销（Ctrl+Z 退两步）、
  oto 保存时重排未改动字段、Icon.vue 的 TDZ、stores/singer.ts 缺 ref 导入导致整页起不来。

## 编辑（钢琴卷帘）

- **工作台骨架**：菜单条 / 工作区预设 / 上下文任务条 / 检查器分页 / 状态栏 / 快捷键速查。
- **18 条参数化 MIDI 工具**（拖动即预览、可存预设）+ 音符级快捷操作（悬停工具条、右键直达参数工具、
  Alt / Shift 拖拽矩阵、Ctrl+Shift+P 命令面板）。
- **步进输入**、列表编辑器即时生效、三视图联动、鼓组命名、按音阶着色；
  **技法条**（Key Switch 段落的显示 / 切换 / 插入）与**逐点速度轨**（自动重算秒数、可撤销）。
- **跨轨编辑**：多轨一起选择与处理，一次撤销；CC 泳道目标从 5 条扩到 17 条。
- **表达映射**支持 PC / CC / 力度系数，技法不再只有键位。

## 乐谱与识谱

- 变谱支持**图片 / PDF / MIDI**，内置自研光学识谱引擎；可多选、拖拽导入；
- 多后端识别（**Audiveris**）可在应用内一键安装；
- 乐谱页新增**校对底图**（对着参考谱逐音校对）；乐谱可就地编辑并写回 MIDI。

## 界面与可访问性

- **密度三档**真正生效（紧凑 / 标准 / 宽松）；**全局 UI 缩放** 0.9~1.3；**色盲友好配色**（Okabe-Ito 八色板）；
  **主题跟随系统**。
- **触控笔与触屏**：手掌误触抑制、长按当右键、笔压。
- 调教页一轮 UX 复核（工具命名、作用域标签、去重、详情面板改成真开关、项目条换行不再裁掉保存按钮、
  首轨自动选中），并给「调教 / 声部轨 / 曲库 / 伴奏轨 / 渲染 / 乐句 / 音素 / 颤音 / 效果链 / 自动化 / 吸附 / 音阶」
  等术语就地补了说明。

## 体积

| 指标 | beta.2 | beta.3 |
| --- | --- | --- |
| 完整安装包 | 673.9 MB | **608.5 MB** |
| 离线更新包 | 151 MB | **143.7 MB** |
| 安装后 `app.asar` | 88.0 MB | **13.0 MB** |
| 内置 Python 运行时 | 1477 MB | **1239 MB** |

- 安装后的 asar 此前把内置音色库、合成器等大文件**同时内联又解包存了两份**（重复 36.9 MB），还带进了开发残留；
  现在部署到安装版的脚本与发布版共用同一套过滤规则，安装版是发布版的忠实镜像。
- 内置 Python 运行时裁掉约 265 MB 运行期用不到的东西：`*.pdb` 调试符号、`*.lib` 静态导入库、`__pycache__`、
  测试套件与 CPython 头文件。裁剪后引擎六组依赖自检（通用 / 钢琴 / 分离 / MuScriptor / Aria / Transkun）仍然全部通过。
- 删掉 19 MB 没有任何引用的历史资源（含一份不可商用的汉仪字体、两个早已停用的乐谱引擎）；
  打包不再带上 sql.js 里 15 个用不到的文件。

## 修复与改进

- **切到 English / 日本語 后部分界面仍是中文**：数据分析页的九张统计卡、转录页的预设名与质量档位在模块加载时
  就取了译文，语言切换不会重新求值。实测英文模式 41 处残留，现降到只剩声库名等用户数据。
- **更新与下载默认直连 GitHub**，不再把所有用户都绕经第三方加速代理；代理只作为失败后的回退源。
- **依赖声明补齐**：PyYAML / Pillow / mido / MuScriptor 此前靠别的包顺带装上，现已显式声明；
  CI 改为安装产品实际使用的那份清单（原先是遗留的桌面版清单，会装一整套用不到的 Qt 界面）。
- **插件沙箱单一来源**：进程内与 worker 沙箱此前各抄一份白名单且已漂移（worker 侧少 `structuredClone`，
  同一个插件在两种模式下行为不同）。
- GPU 算力与 CUDA 增强包不匹配时不再整次转录失败，自动改用 CPU（issue #20）；可视化页背景的三个实测问题、
  沉浸模式透明底色、导出循环里的死变量、图标全量审计发现的问题一并处理。
