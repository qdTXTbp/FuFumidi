# FuFumidi v5.0.0-beta.3

**内测版**。主题：**更小的安装包**、**多语言不再半途失效**、**少绕第三方代理**。

> 测试版（prerelease）：仅「设置 → 更新 → 测试版通道」开启的用户可收到。

## 体积

- 安装包 **608 MB**（上一版 674 MB）。内置 Python 运行时裁掉了约 265 MB 运行期用不到的东西：
  `*.pdb` 调试符号、`*.lib` 静态导入库、`__pycache__` 字节码、测试套件与 CPython 头文件。
  裁剪后引擎自检六组依赖（通用 / 钢琴 / 分离 / MuScriptor / Aria / Transkun）仍然全部通过。
- 安装后的 `app.asar` 从 **88 MB 降到 13 MB**：安装脚本此前把内置音色库、合成器等大文件
  同时内联进 asar 又解包存放了一份（重复 36.9 MB），并带进了开发残留；现已与发布版布局一致。
- 仓库里删掉了 19 MB 没有任何引用的历史资源（含一份不可商用的汉仪字体、两个早已停用的乐谱引擎）。

## 修复

- **切到 English / 日本語 后部分界面仍是中文**：数据分析页九张统计卡、转录页的预设与质量档位
  在模块加载时就取了译文，语言切换不会重新求值。实测英文模式下有 41 处中文残留，现已降到 7 处
  （剩下的都是声库名、语言名这类用户数据）。

## 改进

- **更新与下载默认直连 GitHub**，不再把所有用户都绕经第三方加速代理；代理只作为失败后的回退源。
- **依赖声明补齐**：PyYAML / Pillow / mido / MuScriptor 此前是「靠别的包顺带装上」的隐式依赖，
  现在写在引擎依赖清单里；CI 也改为安装产品真正使用的那份清单（原先是遗留的桌面版清单，
  会装一整套用不到的 Qt 界面）。
- **插件沙箱单一来源**：进程内沙箱与 worker 沙箱此前各抄一份白名单，且已经漂移
  （worker 侧少了 `structuredClone`，同一个插件在两种模式下行为不同）。

## 验证

- 干净 Windows 11 虚拟机（VirtualBox 基线快照）内完成**安装 → 使用 → 卸载**全流程：
  安装包 SHA-256 校验一致；静默安装（`/S /currentuser`）后应用可启动、引擎六组依赖自检全绿；
  卸载后程序文件与注册表项移除、用户数据目录按设计保留。
- 安装版跑通新手引导全部 13 章 95 步，无「找不到目标」的步骤；界面冒烟 0 条 console 错误。
- 门禁：前端构建通过、类型检查 0 错误、UI 测试 137/137、插件沙箱 6/6。
