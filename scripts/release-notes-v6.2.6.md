# FuFumidi 6.2.6

发布于 2026-10-24。本版只动模型分发：乐器组标签模型纳入资源中心统一管理，hFT 权重改从自有仓库下载。**不含任何转录行为改动**（数据目录修复与「音色稳定」恢复见 6.2.5）。

## 乐器组标签模型（AudioSet）纳入统一管理

「音色稳定」（自动锁定乐器组）用的探测器 —— AudioSet zipformer-small（int8 ONNX，20.8MB）——
此前只随包分发（压在安装包与 git 仓库里），既不进资源中心、也不可更新。现在：

- 资源中心 → 转录模型 新增「乐器组标签模型（AudioSet）」，与其它模型走**同一条**
  统一下载/管理通道（下载 → 校验 → 解包 → 结构验收 → 清理临时产物）。
- 解包到 `<数据根>/models/audio-tagger`；引擎查找顺序改为**下载副本优先于随包那份**，
  所以装了新的一份就会被用上。
- 随包那份**保留**作离线兜底：即使没下载，音色稳定也照常工作（不会因为没装这个而失效），
  设置/资源中心里如实显示为「随包附带」。

## hFT-Transformer 改从自有仓库下载

原来直连 `github.com/sony/hFT-Transformer/releases/...` —— 国内经常连不通，而且上游
一旦删掉 release 我们就断供。现在改从**自有的双端 models 仓库**（GitHub `monologue82/Models`
与 CNB `FuFuCloud-mirror/Models`，Release 资产 `models-extra-v1`）下载，国内可直取。
权重字节未变（sha256 与原注册表值逐位一致），只是换了宿主。
