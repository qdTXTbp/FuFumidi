# FuFumidi v5.0.0-beta.2

**5.0 的第二个内测版**。主题：**「调教」单入口**、**OpenUTAU 式编辑深度补齐（P0→P2）**、
**全局热键**、**应用内插件中心**。

> 测试版（prerelease）：仅「设置 → 更新 → 测试版通道」开启的用户可收到。

## 新增

### 「调教」页：歌声合成与声库合成一个入口
- 原来的「歌声合成」与「声库」两页合并为 **调教**：左侧轨道列表，右侧编辑器（卷帘 + 音符检查器 + 渲染），
  顶部页签在「编辑器 / 声库」之间切换。两件事本就是一条工作流的两半。
- 声库面板改为**不透明面板**，长列表可读（此前半透明背景下字与背景糊在一起）。
- UTAU 声库资源统一进「资源管理 → 模型管理」，与 DiffSinger 声库同一处。

### 调教编辑器：P0 正确性 → P1 提速 → P2 编辑深度
- **P0**：修正音量/GENC 语义（只在用户真的设过时才下发参数，避免 legacy 引擎整轨静音）、
  留空即默认的占位提示、**全局撤销栈**（音量/效果链/自动化/歌词/轨名都能 Ctrl+Z）、
  工具条拆成「工程 | 轨道 | 渲染」、渲染按钮禁用时写明原因、空态三步引导。
- **P1**：选歌手改**点选**（声库列表，含引擎联动）；渲染完**自动装载并试听**、可停止后续渲染；
  页面级快捷键；**统一提示**（全应用一个 toast 出口，带「下一步」与可展开详情）；
  轨道列表拖拽排序 / 静音 / 独奏 / 右键菜单 / **渲染已过期徽标**；
  传输栏补 **循环区间 A/B**（到 B 点回 A，走传输器时钟层）、**跟随播放滚动**、0.5×~2× 变速、时间码点击跳转。
- **P2**：卷帘 **复制/剪切/粘贴/重复**（Ctrl+C/X/V/D）、**在播放头切分**（Ctrl+E）、**合并同音高**（Ctrl+M）、
  **播放头竖线**、**音阶高亮**（大调/小调 + 根音）、批量填词、渐强/渐弱力度斜坡；
  **音素级编辑**（条带点选音素 → 单独改 vol/vel/dyn/atk/dec/shft/clr，引擎按音素下标优先）；
  **工程级参数**（拍号驱动小节线、对齐偏移整体平移、BPM 说明）；
  **参数车道**（自动化从「表格加点」升级为可拖拽曲线车道，一格拖拽 = 一步撤销）；
  **声库可用性提示**（歌词不在声库别名表里时行内标红并给相近别名，不用等渲完才在 warnings 里看到）。

### 全局热键（操作系统级）
- 后台播放时可自定义**系统级**快捷键：播放/暂停、上一首/下一首、切换播放模式、切换歌单（编号 1-9）。
- 快捷键由**用户自己录制**，录完立即生效；被系统占用时明确提示「被占用，未生效」。

### 应用内插件中心
- 顶栏与首页新增 **插件中心** 入口，应用内浏览官方插件平台并一键安装（不唤起浏览器）。
- 下载后先把包内清单摊给用户确认，再解压安装并**立即启用**；「已安装」页签管理本地插件开关、日志与目录
  （设置里原来的插件页已整页并入这里）。
- 内置插件只保留 **自动转 C 大调 v1.0.0**，其余示例插件删除。

### 其它
- 歌单编号（1-9）与全局热键联动；轨列表加渲染过期徽标。
- 新手引导、四语文案（简/繁/英/日）随新增功能同步补齐。

## 修复
- `renderAll()` 中断渲染时的 `ReferenceError`（循环变量声明在 try 内）。
- `SingTrack.renderSig` 类型缺失；渲染过期判定改用**每轨**指纹。
- 插件页从设置中移除后，`settingsTab` 不再出现无效项。
