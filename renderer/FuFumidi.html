编辑功能详细说明

🎹 钢琴卷帘
选择/画笔/橡皮三种工具；拖拽移动音符、边缘拉伸改时值、Alt 拖拽调力度；支持吸附、音阶吸附、撤销/重做。
📊 CC 自动化
展开 CC 泳道后可选择 CC1/7/10/11/64；支持手绘、直线、曲线三种绘制；点击/拖动直接写 CC 数据；悬停显示数值。
🔑 Key Switch
C-2~C0 区域橙色高亮；支持自定义技法名称，并提供 Spitfire/VSL/EastWest 预设模板。
🧩 逻辑编辑器
按“目标→条件→操作”批量修改音符：力度、时值、音高、删除、量化、移调。
📋 列表编辑器
以表格精确编辑每个音符的起点/终点/音高/力度；支持添加、删除、排序。
⚡ 宏系统
内置清理/移调/力度标准化宏；支持自定义命令宏和录制宏。
🎚 智能量化
按 1/4、1/8、1/16、1/32 量化；支持 Funk/Jazz/Rock/Latin/自定义 Groove；可提取选中音符的 Groove。
🥁 鼓组编辑器
打击乐专用网格视图，点击添加/删除鼓点，支持鼓轨切换与清除。
🎬 影视配乐
SMPTE 时间码显示；嵌入视频轨道并同步播放；乐谱同步与分屏预览，点击谱面音符定位到钢琴卷帘。
🖥 全屏与布局
全屏按钮最大化钢琴卷帘；新建空白 MIDI 从零开始；默认图标+折叠工具栏，右侧属性检查器精确修改。

关于 FuFumidi

FuFumidi · v2.0.9

离线 MIDI 播放 / 编辑 / 可视化 / 分析 / 乐谱 / 转录（音频转 MIDI）一体工具。

完全本地运行，音频不会上传；内置 Python、依赖与模型，安装后无需联网。

核心功能
  • 音频转 MIDI：通用 / 钢琴 / 人声分离
  • 钢琴卷帘：CC 自动化、Key Switch、逻辑/列表/宏、智能量化、鼓组编辑
  • 演奏可视化、MIDI 分析、五线谱
  • 影视配乐：SMPTE、视频轨道、乐谱分屏
  • 批量转录、模型管理、插件系统、工程文件
技术信息
  • Electron 33.4.11
  • 内置 Python 运行时 + 全部依赖与模型
  • 完全离线，无遥测
GitHub: https://github.com/qdTXTbp/FuFumidi
