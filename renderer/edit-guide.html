🎹 FuFumidi 编辑功能详细说明

从钢琴卷帘到影视配乐，覆盖全部专业编辑能力

🎹 钢琴卷帘

选择 / 画笔 / 橡皮三种工具；拖拽移动音符、边缘拉伸改时值、Alt 拖拽调力度；支持吸附、音阶吸附、撤销/重做、复制/粘贴、量化、移调、力度曲线、同音高/和弦批量选择、删除短音。

📊 CC 自动化

可折叠 CC 泳道，支持 CC1 / CC7 / CC10 / CC11 / CC64；手绘、直线、曲线三种绘制模式；点击/拖动直接写 CC 数据；悬停显示数值；支持双泳道并行。

🔑 Key Switch

C-2 ~ C0 区域橙色高亮；支持自定义技法名称；内置 Spitfire / VSL / EastWest 预设模板；管弦乐采样音源技法切换一目了然。

🧩 逻辑编辑器

按“目标 → 条件 → 操作”批量修改音符：力度、时值、音高、删除、量化、移调；适合触发阈值修复、碎片清理、声部重组。

📋 列表编辑器

以表格精确编辑每个音符的起点/终点/音高/力度；支持添加、删除、排序；适合精细数值控制。

⚡ 宏系统

内置清理工程 / 批量移调 / 力度标准化；支持自定义命令宏；支持录制宏，把常用操作一键化。

🎚 智能量化

按 1/4、1/8、1/16、1/32 量化；支持 Funk / Jazz / Rock / Latin / 自定义 Groove；可提取选中音符的 Groove 模板。

🥁 鼓组编辑器

打击乐专用网格视图，行=鼓音高、列=拍；点击添加/删除鼓点；支持鼓轨切换与清除。

🎬 影视配乐

SMPTE 时间码显示；嵌入视频轨道并同步播放；乐谱同步与分屏预览；点击谱面音符可定位到钢琴卷帘对应音符。

🖥 全屏与布局

全屏按钮最大化钢琴卷帘；新建空白 MIDI 从零开始；默认图标+折叠工具栏；右侧属性检查器精确修改；列表/逻辑/宏/量化/鼓组均有独立入口。
