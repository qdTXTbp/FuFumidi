把音乐创作带进离线世界

FuFumidi 是一款完全离线的桌面音乐工具，集 MIDI 播放、编辑、可视化、分析与转写于一身，内置 Python 引擎与 AI 模型，断网也能完成从音频到乐谱的全流程创作。

GitHub 主页 探索功能
开源 跨平台桌面 内置 AI 模型

功能

钢琴卷帘编辑

音符、力度与 CC 自由编辑，精细到每一次触键。

智能音频转写

basic-pitch 与 CRNN 钢琴模型，把音频一键变成 MIDI。

人声分离

内置 Demucs，快速提取伴奏与人声轨。

瀑布流可视化

Synthesia 风格键盘瀑布，演奏模式轻松上手。

五线谱乐谱

Verovio 引擎渲染，乐谱可读、可导出。

CC 自动化

弯音、调制、表情曲线随心绘制。

键位映射

键位切换映射，让演奏更顺手。

宏系统

把重复操作录制成一键指令。

所见即所得的工作台

播放器、钢琴卷帘与瀑布流同屏协作

乐谱、分析、转写视图一键切换

主题与壁纸自由更换，界面由社区贡献者精心打磨

技术栈与能力

Vue 3 前端 Rust · Tauri 桌面核心 Python 音频与转写引擎 WebAssembly 合成器与谱面引擎 离线模型与音色库打包 跨平台安装包

影视配乐

支持 SMPTE 时间码与视频对齐，边看画面边配乐

全离线运行

Python、模型、音色库全部内置，安装即用，无需联网
