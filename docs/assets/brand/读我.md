## 选型（2026-10 用户拍板，别再改回去）

| 位置 | 用什么 | 为什么 |
|---|---|---|
| exe / 安装器 / 窗口 / 托盘图标 | **头像特写 + 透明底** | 用户明确要求「图标要抠白底」：白底圆角卡在深色任务栏上是一块白板 |
| 侧边栏徽标（38px）、文档页 nav（36px） | **头像特写 + 透明底** | 方形小位放立绘只剩一条竖线，认不出人 |
| **首页工作区吉祥物** | **立绘整幅**（高 168px，右对齐） | 用户要求「立绘放到工具里」；工具内最大的静态位就是首页页头 |

**不要手工改这些文件** —— 它们是流水线的产物。换 logo 的流程：
改母图 → 重跑 `logo3.py` / `mkicon.py` → 覆盖本目录的母图 → 跑 `scripts/gen-logo.py`
（它会重出图标 + 侧栏/文档徽标 + 首页立绘，并断言"角落必须透明"）。
