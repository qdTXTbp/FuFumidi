## 本目录存了什么

| 文件 | 用途 |
|---|---|
| `FuFumidi.ico` | **主图标**（白底立绘，含 256/128/64/48/32/16）→ `build/icon.ico` |
| `立绘-白底-512.png` | 窗口 / 托盘图标 → `build/icon.png`；也是安装器页眉的小图源 |
| `立绘-深靛-512.png` | 侧边栏 + 文档页 nav（浅色底上要它） |
| `徽记-512.png` | 安装器侧栏 / 更新器左图（完整方形徽记） |
| `立绘-定稿-透明.png` | 立绘母图（透明底），留档用 |

**不要手工改这些文件** —— 它们是流水线的产物。换 logo 的流程是：
改 `logo3.py` 的母图 → 重跑 `logo3.py` 与 `mkicon.py` → 把上面 5 个文件重新拷进来 → 跑 `scripts/gen-logo.py`。

选型表（哪个位置用哪个变体、为什么）在 `scripts/gen-logo.py` 的文件头，
以及 `docs/REA-installer-and-updater.md` 的「品牌资产流水线」一节。
