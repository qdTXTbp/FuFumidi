## 4. 发现的问题

1. **界面长求值探针的响应会被 NAT 丢掉**（既有已知问题，TESTING.md §3.1 已记录）：视图/语言/转录三个探针都在 180-240 s 处报"求值超时"，但结果其实已在页面里跑完，从 `window.__l3Views / __langProbe / __l3Transcribe` 短求值取回即可。本轮 `expr-guest-misc.js`（主题真点 + 沉浸模式 + 2 万音符导入）**未取到结果**，属未覆盖项。
2. **guest-run 取回的 UTF-8 输出在宿主机侧显示为乱码**（依赖自检的 JSON 如此）—— 这是 guest-run 通道的显示编码问题，不是产品问题：应用内文本由四语言探针单独验证通过。
3. **本机 `npm run test:download` 在负载下抖动过一次**（与 pytest/构建同批跑时 1 项失败；单独安静连跑两遍均 15/15）。属时序敏感的测试环境抖动，非产品缺陷，但记在这里。
4. 可视化主画布之外的两个画布采样到的已绘制像素只有 2 / 5 个（可能本来就只有叠加层），不影响判定，留待后续观察。
