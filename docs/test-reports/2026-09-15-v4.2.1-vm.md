## 环境准备（本机专属，非产品问题）

宿主机开着 Hyper-V/VBS 时 AMD-V 被 Windows 虚拟机监控程序独占，VirtualBox 只能跑
`NEM: Snail execution mode is active!` 蜗牛模式 —— 装 Windows 要 1 小时多，中途 guest
长时间无响应、ACPI 关机不生效。已按 `docs/TESTING.md` 第 2.6 节关闭
`hypervisorlaunchtype` + `EnableVirtualizationBasedSecurity` + HVCI 并重启，
之后 VBox.log 显示 `HM: HMR3Init: AMD-V w/ nested paging`，安装耗时降到约 2.5 分钟。

## 发现的问题

1. **（已在 4.2.1 修复）** 内置运行时缺 VC++ 运行库 / aria / transkun 依赖 —— 干净系统上转录引擎整条不可用
2. **（已在 4.2.1 修复）** 卸载会静默删除用户数据，现改为询问（默认保留）
3. **（未修，记入下一版候选）** 引擎转码临时文件不回收：`engine/audio_io.py` 的 `tempfile.mkstemp(prefix="midi_tool_")`
   会在 `%TEMP%` 留下数百 MB 的 WAV。本次测试机清出 12 个共 1.34 GB
4. **（未修，记入下一版候选）** 首次启动「更新内容」弹窗只列到 v3.1.3，4.2.0/4.2.1 的 changelog 未进包
