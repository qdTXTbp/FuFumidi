# FuFumidi 6.5.0 — AI 实现规格

> 本文件是 6.5.0 的**机器优先规格**。AI/协作者按本文件实现；人类背景读 `human_doc`。
> 所有需求有 ID；所有任务有依赖；所有验收可映射到 ID。

## 0. AI 使用规则

1. 先读 `AGENTS.md` 和本文件，再改代码。
2. 不实现 `non_goals`；不新增页面；不训练模型。
3. 每个改动必须对应至少一个 `REQ-*`，并在提交信息引用 ID。
4. 不修改现有 2D 仪表盘/瀑布流默认路径；3D 和分轨都是增量入口。
5. 不构建安装包、不上传 Release，除非用户明确要求。
6. 失败要回退：分轨失败→整曲转录；3D 掉帧→降质/2D；模型缺失→降档。
7. 改完运行 `npm test`、`npm run typecheck`、相关 `pytest`。
8. 新增外部依赖必须说明体积/许可；默认只允许 `three`。

## 2. 决策记录

| ID | 决策 | 理由 |
|---|---|---|
| D-001 | 分轨固定 `HTDemucs4_6stems.th` | 2-stem duality 不能保证音色稳定 |
| D-002 | 默认转录固定 YourMT3+；Basic Pitch 降级 | 避免用户装六套模型 |
| D-003 | 分轨入口不新增页面，只加开关 | 最少步骤 |
| D-004 | 每轨只保留一个 `program_change` | 直接消除音色跳变 |
| D-005 | 30+ 轨只承诺工程内保留；MIDI 导出分组 | 标准 MIDI 16 通道硬限制 |
| D-006 | 3D 用 Three.js，不引入 React/Babylon | 与 Vue 集成成本最低 |
| D-007 | 3D 钢琴默认程序化建模 | 避免版权/包体风险 |
| D-008 | 3D 是 ViewViz 新模式，不新建路由 | 保持入口一致 |
| D-009 | 外接 MIDI 复用 `midiin.js`/`recorder.js` | 已有能力，不重写 |
| D-010 | 研究模型（MDTK/RefinPaint/MIDBACK）不进 6.5.0 必需路径 | 权重/许可/成本未定 |

## 4. Feature A 规格

### 4.1 用户流程

```text
拖音频 -> 选模型(可默认) -> 保留轨道(默认自动) -> 开始
```

唯一新增控件：

```text
[✓] 智能分轨（推荐）    保留轨道：自动（建议 12 轨） ▾
```

### 4.2 请求契约

```ts
interface TranscribeCfgExt {
  stemEnhance?: boolean;
  trackBudget?: 'auto' | 6 | 12 | 16 | 'all';
  stemSepModel?: string;      // internal default: HTDemucs4_6stems
  stemTranscriber?: string;   // internal default: yourmt3
}
```

### 4.3 进度事件

```ts
type StemProgress = {
  id: string;
  stage: 'separate' | 'transcribe' | 'refine' | 'merge' | 'done';
  stem?: string;
  current?: number;
  total?: number;
  candidates?: number;
  text?: string;
};
// channel: engine:stem-progress
```

### 4.4 结果契约

```ts
interface StemResult {
  ok: boolean;
  out: string; // merged.mid
  candidates: number;
  tracks: Array<{
    id: string;
    role: 'vocals'|'drums'|'bass'|'piano'|'guitar'|'other'|string;
    name: string;
    model: string;
    program: number;
    channel: number;
    noteCount: number;
    confidence: number | null;
    action?: 'keep'|'merge'|'drop';
    mergedInto?: string;
  }>;
  export?: { mode: 'single'|'multi'|'project'; files: string[] };
}
```

### 4.5 模型与分档

```yaml
models:
  separator_primary: HTDemucs4_6stems.th
  separator_fallback: bs_roformer_4stems_ft.ckpt
  transcriber_primary: yourmt3
  transcriber_builtin_fallback: basic
  tagger: audio-tagger (bundled 20.8MB)
forbidden_default:
  - melband_roformer_instvox_duality_v2
```

分档：

| available | behavior |
|---|---|
| 6-stem + yourmt3 | full |
| 6-stem + basic | degraded |
| only transcriber | whole-mix + split |
| none | basic whole-mix |

### 4.6 固定音色

```yaml
roles:
  vocals: { program: 52, channel: 0 }
  drums:  { program: 0,  channel: 9, drum: true }
  bass:   { program: 33, channel: 1 }
  piano:  { program: 0,  channel: 2 }
  guitar: { program: 24, channel: 3 }
  other:  { program: 48, channel: 4 }
rules:
  - one program_change per track
  - strip all later program_change
  - split track if original has multiple programs
  - pitched percussion stays melodic
```

### 4.7 轨道预算

```text
selectTracks(candidates, target):
  core = drums, vocals, bass, piano, guitar (max 1 each)
  score = sqrt(noteCount) * confidence * roleWeight
  if target == 'auto': target = clamp(6, 12, roots)
  keep core; fill by score; if target < core: merge low-confidence extras
  if target > candidates: split by program/pitch range
  never merge drums into melodic
```

### 4.8 超 16 轨导出

```yaml
export:
  <=16: single_midi
  >16:
    project: keep_all
    midi: grouped_files
    warning: "MIDI 16 通道限制"
```

```yaml

  perfect: 25
```
