# FuFumidi 前端品牌化改造方案（2026-10-22）

> 状态：方案已定，视觉验证进行中；**尚未改动业务代码**。
> 目标：在不改变 IPC / 引擎 / 路由 / Pinia / 持久化协议的前提下，把现有前端收敛为「深海录音室」品牌工作台。
> 视觉验证：`E:\Midi\_attic\fufumidi-ui-proto-v3\index.html`（本地方案验证稿，示例数据）。

---

## 0. 一句话

以现有 logo 的**深靛画布 + 鎏金细框 + 蓝宝石高光**为母语，把米哈游式「暗色舞台 / 结构边框 / 密度」作为语法，而不是照搬抽卡界面；以**海蓝、天蓝、蓝宝石**作为 UI 强调色，金色降级为装饰线。主题库与动态壁纸完整保留，并让动态壁纸和普通静态壁纸共用同一条背景管线。

---

## 1. 硬约束

1. **纯前端改造优先**：不改 engine / main 的业务逻辑与参数。
2. **原有功能不失效**：
   - 主题库 12 套主题、浅色/深色/跟随系统、自定义强调色、图片取色主题全部保留；
   - `fufumidi_theme`、`fufumidi_mode`、`fufumidi_accent` 等持久化键不变；
   - 动态壁纸的视频播放、循环、防冻结、壁纸库下载、本地导入、瀑布流背景全部保留；
   - 路由 hash、深链接、文件关联、`data-guide`、E2E 钩子不变。
3. **失败可回退**：新壳用 `fufumidi_ui_v2` 开关，关闭后回旧界面；不迁移数据。
4. **不引入运行时依赖**：不新增 npm 运行时包，不联网取字体/图标。

> 普通壁纸进入「壁纸库/应用数据目录」需要 main 侧 `wallpaper.js` 做**加法扩展**（允许图片扩展名、返回 kind）；外壳、页面、静态壁纸渲染与本地选择属于前端。若必须零 main 改动，则普通壁纸只能走“选择本地图片 → 直接写 custom_wallpaper”的降级路径，无法进入壁纸库。建议允许 add-only IPC 改动。

## 2. 视觉母语与三色语义

### 2.1 来源

### 2.2 强调色分工

| 角色 | 建议值 | 用途 | 禁止 |
|---|---|---|---|
| 海蓝 Sea | `#2F7FA8`，深底 `#06131F` | 品牌环境、导航底纹、选中背景 | 大面积主按钮 |
| 天蓝 Sky | `#69C8F0` | 焦点环、hover、链接、信息、进度高光 | 成功/危险状态 |
| 蓝宝石 Sapphire | `#2F63D4` / 亮 `#3D74E8` | 主按钮、当前步骤、选中项、关键数字 | 装饰背景 |
| 鎏金 Ornament | `#D2B679` | logo 边框、四角饰线、四星、分隔线 | 普通按钮 / 选中态 |

原则：一屏只有一个主操作；主操作用蓝宝石；天蓝只做交互反馈；海蓝负责氛围；金色只负责“贵气”。

### 2.3 核心 token（草案）

```css
:root[data-theme="dark"] {
  --stage: #06131F;
  --panel: #0A1B2A;
  --raised: #102738;
  --line: rgba(111,168,204,.16);
  --line-strong: rgba(105,200,240,.30);
  --text: #EAF3FA;
  --text-soft: #A8BAC8;
  --text-dim: #718695;
  --accent-sea: #2F7FA8;
  --accent-sky: #69C8F0;
  --accent-sapphire: #2F63D4;
  --accent-sapphire-bright: #3D74E8;
  --ornament: #D2B679;
  --t-ok: #67D3A5;
  --t-warn: #E6B45E;
  --t-err: #F47C86;
  --t-info: #69C8F0;
}
```

主题仍由 `core/theme.js` 的 `paletteFor()` 发布；新增语义角色映射：

- `--accent` = 蓝宝石（主操作）
- `--accent-2` / `--t-info` = 天蓝（交互/信息）
- `--accent-sea` = 海蓝（环境）
- `--ornament` = 金（装饰，不参与强调色）

### 2.4 新增默认主题

- 新增 `ocean` / “深海蓝宝石”主题，作为新安装默认；
- 现有 12 个主题 ID 全部保留，老用户已有选择不动；
- 现有主题的强调色可以保留自己的色相，但新增的边框/角饰/状态色统一走语义 token，避免各主题各写一套。
- 浅色主题仍完整支持；浅色下蓝宝石按钮需压深以保证对比度。

## 4. 页面方案

### 4.1 首页

- “继续上次” hero：曲名、波形、进度、继续/打开工程；
- 系统就绪：GPU、MuScriptor、YourMT3+、MIROS、更新；
- 拖入音频是唯一主导入动作；
- 最近项目用表格；
- “接下来”只保留 3 个入口。

### 4.2 转录

三栏：

- 左：素材与队列；
- 中：配方（模型、质量、乐器组、模型专属参数、高级参数折叠）；
- 右：运行（开始、进度、ETA、失败恢复、日志入口）。

规则：

- 模型卡片就地显示已安装/未安装/下载；
- 参数按模型 schema 渲染；
- MuScriptor 片段长度固定 5.0s，显示“模型固定”，不允许 30s；
- 主按钮固定，不埋在参数末尾；
- 多队列收进抽屉；
- 完成提示音、任务中心、暂停/恢复保持现有逻辑。

### 4.3 曲库

- 表格 + 左侧筛选 + 右侧预览；
- 列：曲名 / 时长 / 轨道 / 调性 / 标签 / 最近播放 / 状态；
- 批量操作：加入歌单、重新转录、导出、删除。

### 4.4 工作台

- 左工具轨、中画布、右检查器；
- 画布保持不透明，壁纸不进入钢琴卷帘/谱面内部；
- 编辑/乐谱/分析/可视化共用外壳。

### 4.5 设置与资源

- 设置：外观、行为、音频、快捷键、关于；
- 资源：模型、音色、声库、插件、诊断；
- 外观是主题与壁纸唯一入口。

## 6. 壁纸系统：动态 + 普通壁纸

### 6.1 现状

- `App.vue` 只渲染 `<video>`；
- 壁纸库只接受视频；
- 本地导入只允许 `mp4/webm/mov`；
- 设置键 `wallpaper_enabled` + `custom_wallpaper`；
- 有视频防冻结 watchdog。

### 6.2 目标模型

```ts
type Wallpaper = {
  kind: 'image' | 'video' | 'animated';
  path: string;
  fit: 'cover' | 'contain';
  dim: number;      // 0-60
  blur: number;     // 0-20
  motion: 'auto' | 'pause';
}
```

旧字段保留，新增字段全部可选：

```
custom_wallpaper
wallpaper_enabled
wallpaper_kind?: 'image'|'video'|'animated'
wallpaper_fit?: 'cover'|'contain'
wallpaper_dim?: number
wallpaper_blur?: number
wallpaper_motion?: 'auto'|'pause'
```

读取顺序：`wallpaper_kind` → 扩展名 → 图片解码探测 → 回退主题背景。

### 6.3 渲染

新增 `WallpaperLayer`：

- image：`<img class="app-wallpaper">`
- video：`<video muted autoplay playsinline>`
- animated：`<img>`（GIF/WebP，按普通壁纸）
- 视频的循环/防冻结/窗口隐藏暂停逻辑原样迁入；
- 视频加载失败显示 poster 或主题渐变，不黑屏；
- `prefers-reduced-motion` 或用户暂停时视频停首帧。

### 6.4 壁纸库/导入

- 保留 app / viz 双目标；
- 列表不再强制过滤 `video`，按 `kind` 区分；
- 本地导入扩展名：视频 `mp4/webm/mov`；图片 `jpg/jpeg/png/webp/avif/gif`；
- main `wallpaper.js` 的 `addLocal/list` 做加法扩展，返回 `kind`；
- 现有视频路径/URL/删除/下载进度不改。

### 6.5 设置 UI

外观面板：

- 主题：浅色/深色/auto、主题库、强调色；
- 壁纸：普通壁纸 / 动态壁纸页签；预览、壁纸库、导入、适应方式、暗度、模糊、暂停；
- 动效：减少动态效果、任务运行时暂停视频壁纸；
- 普通与动态共用同一条背景管线，切换自动替换，不残留两个图层。

### 6.6 可读性

- 壁纸层统一 scrim，默认 18–30%；
- 面板/表格/输入框使用实底或高不透明度；
- 浅色主题 + 浅色壁纸用浅色 scrim；
- 正文对比度 ≥ 4.5:1；提供“清晰/柔和/沉浸”预设。

### 6.7 性能

- 单视频实例；
- 页面隐藏暂停；
- 任务运行时可自动暂停视频壁纸；
- 视频加载失败降级静态/主题；
- 图片壁纸无 CPU 成本。
