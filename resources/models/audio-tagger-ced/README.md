# CED-Small audio tagger

From sherpa-onnx-ced-small-audio-tagging-2024-04-19 (k2-fsa/sherpa-onnx audio-tagging-models release).

- model: CED-Small, 527 AudioSet classes, int8 ONNX (~22 MB)
- input: 64-bin log-mel features, 16 kHz
- source code: https://github.com/RicherMans/CED
- exported by: https://github.com/k2-fsa/sherpa-onnx
- labels: class_labels_indices.csv (AudioSet)

Used only as an optional instrument-group probe; it does not generate MIDI.
