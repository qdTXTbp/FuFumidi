# Intel XPU 加速包（torch+xpu / oneAPI）—— Intel Arc 独显与部分核显
#
# ★ 与 cuda 包互斥：xpu 版 torch 是**独立构建**，不带 CUDA，两者不能同时挂。

# ★ ONNX 侧配 onnxruntime-directml：Intel 没有 onnxruntime-xpu，
#   而 engine_gpu.py 认的是 DmlExecutionProvider / CUDAExecutionProvider。
#
# 构建时必须走镜像：download.pytorch.org 实测只有 313 KB/s，
# SJTU 的 pytorch-wheels 镜像实测 14.5 MB/s（差 46 倍），否则光下载就要 1-2 小时。
